# 分析シート

毎回の授業で使うシートです。「たどる面」と「降ろす面」の2面でできています。たどる面は毎回すべて書きます。降ろす面は、1年前期は形容詞まで、1年後期は具体まで。パラメータまで降ろすのは、AEの授業で技術が身につく2年からです。

## 基本情報

| 項目 | 書くこと |
| --- | --- |
| 回・日付 | 授業の回と日付 |
| 作品名・公開年・媒体 | 映画、アニメ、ゲーム、MVなど |
| 監督・主なスタッフ | 作品データから書き写す |
| 観る前の予想 | 何が起きると思うか |
| 観たあとのズレ | 予想と何が違ったか |

## たどる面①：6つの項目

分かることだけ書けば構いません。空欄は「まだ読めていない場所」です。

| 項目 | 問い |
| --- | --- |
| **レイヤー構造** | 画面は何枚の層でできているか。背景、人物、エフェクト、文字は？ |
| **世界観** | この作品の中で「当たり前」になっているルールは何か |
| **カラコレ・ルック** | 全体は何色に寄っているか。光はどこから来ているか |
| **テンションカーブ** | どこで盛り上がり、どこで落ちたか。一番高い山はどこか |
| **台本構成** | どこで話が転がったか。いくつの段階に分けられるか |
| **源流作品** | この作品は何から来ていると思うか。作り手は何を経てきたか |

## たどる面②：はしごを下からたどる

一番心が動いた場面を1つ選び、観察した事実から順に上へたどります。はしごの考え方は[この授業について](#about)の図1を見てください。

| 段 | 問い |
| --- | --- |
| **4　パラメータ** | 画面と音で、実際に観察できたことは何か（色、光、カメラの位置、構図、カットの長さ、音） |
| **3　具体** | それはどんな演出の指示として書けるか |
| **2　形容詞** | その場面を形容詞3つで言うと |
| **1　抽象** | 作り手は、その場面で何を伝えたかったのか |

## パラメータの引き出し

1年のうちは、パラメータを「作る」必要はありません。観察した言葉を「集める」だけで十分です。書き溜めたものが、2年でAEを使って作るときの引き出しの目録になります。専門用語を知らなければ、自分の言葉で構いません。

| 分類 | 書くこと |
| --- | --- |
| 色 | 観察したこと／場面（何分ごろ）／何を感じさせていたか |
| 光 | 同上 |
| カメラ（位置・動き） | 同上 |
| 構図 | 同上 |
| 編集（カットの長さ・つなぎ方） | 同上 |
| 音・音楽 | 同上 |

## 降ろす面

たどる面で見つけた「抽象」を、自分ならどう降ろすかを考えます。正解はありません。作品と違う答えになって構いません。

| 時期 | 降ろす範囲 | 書くこと |
| --- | --- | --- |
| **1年前期** | 抽象 → 形容詞 | 自分なら、その抽象を別の形容詞3つでどう言い換えるか。作品の形容詞とどこが違うか |
| **1年後期** | 形容詞 → 具体 | それを伝える場面の指示を3つ（時間帯、人物の位置、音の有無など）。引き出しノートで使えそうな観察はどれか |
| **2年から** | 具体 → パラメータ | AEの授業で身につけた技術で、引き出しノートを開いてパラメータまで降ろす |

## 記入例：『DUNE PART2』ジェディ・プライムの闘技場

[第7回](#lesson-07)で扱った場面です。

| 段 | たどる |
| --- | --- |
| 4　パラメータ | 屋外だけ白黒になる。人物の肌が白く浮く。影が濃い。群衆が画面を埋め、主役は中央 |
| 3　具体 | 屋内から屋外に出た瞬間に色が消える。闘技場を大勢が囲む |
| 2　形容詞 | 冷たい／異質／乾いた |
| 1　抽象 | 「話が通じない他者の世界」 |

| 分類 | 観察したこと | 何を感じさせていたか |
| --- | --- | --- |
| 色 | 屋外は白黒。屋内は色がある | 外の世界が異質だと分かる |
| 光 | 肌が白く光って見える | 人間らしさがない |
| 構図 | 群衆が画面を埋め、主役が中央に立つ | 逃げ場がない |

| 段 | 降ろす（前期） |
| --- | --- |
| 1　抽象 | 「話が通じない他者の世界」 |
| 2　形容詞 | 自分なら：無音／整いすぎた／無表情 |
| ひとこと | 作品は「冷たさ」で描いていたが、自分は「整いすぎていて人間味がない」方向で描きたい |
