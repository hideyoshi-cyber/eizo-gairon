# 用語集

授業で使う言葉をまとめました。分からない言葉が出てきたら、ここで確かめてください。右の「関連する回」から、その言葉が詳しく出てくる記事に移動できます。

## 見る・読む

| 言葉 | 意味 |  |
| --- | --- | --- |
| **分析シート** | 作品を読むために毎回使うシート。6つの項目と、はしごをたどる欄、引き出し、降ろす面でできている | [関連する回](#sheet) |
| **はしご** | 抽象→形容詞→具体→パラメータの4段。制作では上から降ろし、分析では下からたどる | [関連する回](#about) |
| **引き出し（引き出しノート）** | 観察した色、光、構図、編集などを集めておくノート。2年で自分の作品を作るときの目録になる | [関連する回](#sheet) |
| **源流** | その作品が影響を受けた、もとになった作品や作り手 | [関連する回](#lesson-28) |
| **テンションカーブ** | 観客の感情の高さを、時間に沿って線で描いたもの。山と谷で構成を読む | [関連する回](#lesson-12) |
| **台本構成** | 物語をいくつの段階に分け、どこで転がすか | [関連する回](#lesson-11) |
| **世界観** | その作品の中で「当たり前」になっているルール | [関連する回](#lesson-13) |

## 画面とカメラ

| 言葉 | 意味 |  |
| --- | --- | --- |
| **ショット／カット** | カメラが回り始めてから止まるまでのひと続きの映像。編集でつないだ一つ一つの単位 | [関連する回](#lesson-04) |
| **長回し** | カットを割らずに長く撮り続けること。または、そう見せる演出 | [関連する回](#lesson-04) |
| **構図** | 画面の中に、何を、どこに、どの大きさで置くか | [関連する回](#lesson-05) |
| **上手（かみて）・下手（しもて）** | 画面の右側と左側。位置関係が観客に与える印象の違いを、演出に使う | [関連する回](#lesson-39) |
| **レイアウト** | アニメで、カメラの位置や構図、背景と人物の配置を決めた設計図 | [関連する回](#lesson-52) |
| **絵コンテ** | カットごとの絵、秒数、セリフ、音を書いた時間の設計図 | [関連する回](#lesson-37) |
| **コマ打ち（1コマ打ち・2コマ打ち）** | アニメで、1秒間に何枚の絵を描き変えるか。動きの細かさを決める | [関連する回](#lesson-24) |

## 光と色

| 言葉 | 意味 |  |
| --- | --- | --- |
| **カラコレ（カラーコレクション）／グレーディング** | 撮影したあとに、色や明るさを整え、作品の色の雰囲気を作る作業 | [関連する回](#lesson-08) |
| **ルック** | 作品全体の見た目の方向性。色、質感、光をまとめた印象 | [関連する回](#lesson-43) |
| **カラースクリプト** | 作品全体の色の流れを、時間に沿って並べた設計図 | [関連する回](#lesson-45) |
| **色温度** | 光の色の暖かさ・冷たさを表す数値。低いと赤っぽく、高いと青っぽくなる | [関連する回](#lesson-48) |
| **彩度** | 色の鮮やかさ | [関連する回](#lesson-48) |

## 合成とCG

| 言葉 | 意味 |  |
| --- | --- | --- |
| **レイヤー** | 画面を構成する層。背景、人物、エフェクト、文字などを重ねて1枚の画にする | [関連する回](#lesson-18) |
| **コンポジット（合成）** | 複数の素材を重ね合わせて、1つの画面にする作業。アニメでは「撮影」と呼ぶことが多い | [関連する回](#lesson-18) |
| **VFX** | 実写の映像に、CGや合成で現実にはないものを足す技術 | [関連する回](#lesson-16) |
| **プリレンダ** | あらかじめ時間をかけて計算しておいた映像 | [関連する回](#lesson-01) |
| **リアルタイム** | その場で計算して描く映像。ゲームのプレイ画面など | [関連する回](#lesson-01) |
| **モーションキャプチャ／パフォーマンスキャプチャ** | 俳優の動きや表情を記録して、CGのキャラクターに移す技術 | [関連する回](#lesson-41) |
| **バーチャルカメラ** | CGの世界の中を、実写のように手で動かして撮るためのカメラ | [関連する回](#lesson-40) |
| **プリビズ** | 撮影や制作の前に、簡単なCGで場面の動きやカメラを検討すること | [関連する回](#lesson-08) |
