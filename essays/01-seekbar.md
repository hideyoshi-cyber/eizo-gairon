# シークバーを、ただ通り過ぎないために　観る側から、作る側へ

**この記事の結論**　映像を観るだけの側にいる限り、学生は振り回され続けます。人の心に残る作品を設計する側に回るためには、作品の構造だけでなく、その作品を生んだ時代と、お金の流れまで知る必要があります。

## 1. 観ることに、覚悟があった時代

僕たちの時代、無料で観られる映像はテレビしかありませんでした。観たい番組は、決められた時間に、決められた場所でしか観られない。テレビ以外で観ようと思えば、レンタルビデオ屋でVHSを借りるか、お金をためてDVDを買うしかありませんでした。

この不便さが、集中力を育ててくれていたのだと思います。手間とお金がかかるから、元を取ろうとして1本を頭に焼き付けるように観る。観ることそのものに、覚悟がありました。

## 2. 情報の飽食と、お菓子だけの食事

今は、スマホがあればどこでも、いつでも、何でも観られます。1本観終わる前に、次のおすすめが流れてくる。情報の飽食です。

この環境で1つの作品を頭に焼き付けるのは、かなり難しいことです。学生の感想は「かっこよかった」「迫力があった」という表層的な印象で止まりがちです。画面というインターフェースを理解しないまま観ていれば、作り手としての気づきがないまま、タイムラインがシークバーをただ通り過ぎていきます。

「今の学生は一瞬で掴む力がある」と言われることもあります。でも僕は、瞬時のキャッチアップは必要ないと考えています。瞬間で掴んだものは、瞬間で忘れるからです。

それは、ずっとお菓子を食べ続けているのと同じです。主食の味が分からなくなり、ファストな情報は血にも肉にもならず、脂肪だけがたまっていく。必要なのは、ちゃんと「美味しい」と思える味覚を養うことです。良い作品をじっくり味わい、なぜ美味しいのかを考える。その積み重ねが筋肉になり、体になります。

## 3. 振り回される側から、操る側へ

一瞬で心を掴むショート動画も、次々に流れてくるおすすめも、誰かが設計したものです。注意を奪うように作られた仕組みを、ただ受け取っているだけなら、それは振り回されているのと同じです。甘いだけのものを味わわされているにすぎません。

では、振り回す側とは何なのか。どこで視線を奪い、どこで感情を動かし、どこで次へ進ませるのか。操るとはどういうことなのか。それを知ることこそ、映像を制作するうえで必要なことです。

もう一つ気になるのが、「これで合っていますか」という質問です。でも、映像に正解はありません。あるのは、作り手が下した判断と、それがどう届いたかだけです。僕は、映像クリエイターとしての素養をこう考えています。

> 世の中に投じられる石を手にして、実際に投げる。そして、そこに広がる波紋を見る。

「合っているか」を考えている間、石は手の中にあるままです。投げない限り、波紋は生まれません。

## 4. なぜ、長く続く作品があるのか

今の時代にも、今の答えはあります。でも作り手に必要なのは、その先です。なぜ何十年も続く作品が存在するのか。

人は物語をハブにして、虚構の中で協力し合うことで社会を成り立たせてきました。だから今も宗教は力を持っています。物語をハブにすること自体は否定しません。問題は、その物語を使って人の心に残る作品を差し出す側に立てるかどうかです。

| 作品 | 始まり | 媒体を越えた広がり |
| --- | --- | --- |
| 鉄腕アトム | 1952年（漫画） | 漫画、テレビアニメ、映画 |
| ゴジラ | 1954年（映画） | 70年以上の映画シリーズ、海外版 |
| ルパン三世 | 1967年（漫画） | 漫画、テレビアニメ、劇場映画 |
| ドラえもん | 1969年（漫画） | 漫画、テレビアニメ、毎年の劇場映画 |
| スター・ウォーズ | 1977年（映画） | 映画、ドラマ、ゲーム、テーマパーク |
| 機動戦士ガンダム | 1979年（テレビアニメ） | アニメ、プラモデル、ゲーム、実物大立像 |
| スーパーマリオブラザーズ | 1985年（ゲーム） | ゲーム、映画、テーマパーク |
| ドラゴンクエスト | 1986年（ゲーム） | ゲーム、漫画、アニメ |

共通しているのは、核になる世界観と登場人物を守りながら、時代ごとに媒体と表現を更新し続けてきたことです。映像概論で2年かけて90年代まで遡るのは、時間というフィルターを通り抜けて、今も残っている作品だけを観るためです。30年経っても語られる作品には、必ず長く続く理由があります。

## 5. 作品の裏には、時代と企業の戦略がある

長く続くIPは、作り手の才能だけで生まれたわけではありません。どの作品にも生まれた時代の背景があり、それを支えた企業の戦略があります。映像は、その中で大きな役割を担ってきました。

| 作品 | 生まれた時代の背景 | 支えた戦略と映像の役割 |
| --- | --- | --- |
| ゴジラ（1954） | 同じ年の水爆実験と第五福竜丸の被ばく事件。核への恐怖 | 東宝の特撮映画として生まれ、シリーズ化と海外展開で70年続くIPに |
| スター・ウォーズ（1977） | 特撮技術が大きく進化した時代 | ジョージ・ルーカスが続編と関連商品の権利を確保。映画が商品とシリーズの入口に |
| 機動戦士ガンダム（1979） | ロボットアニメの全盛期 | 最初の放送は振るわなかったが、プラモデル（ガンプラ）の大ヒットで柱に |
| ドラゴンクエスト（1986） | ファミコンが家庭に広がった時代 | 「週刊少年ジャンプ」と連動し、鳥山明のキャラクターで世界観を広げた |
| ファイナルファンタジーVII（1997） | ゲーム機が3DとCD-ROMの時代へ | 任天堂からPlayStationへ移り、CGムービーが作品の顔に |
| ポケットモンスター（1996） | 携帯ゲーム機と通信ケーブルで「交換する」遊び | ゲーム、アニメ、カード、映画を同時に動かすメディアミックス |
| ルックバック（2024） | 世界同時に配信される時代 | Amazon MGMスタジオが初めて日本アニメの製作委員会に参加し、Prime Videoで世界独占配信 |

映像作品は、それ単体で存在しているわけではありません。ある時は商品を売るための入口であり、ある時はゲーム機や配信サービスの戦略の顔であり、ある時は時代の不安を映す鏡です。

## 6. 映像のお金は、どこから来て、誰の給与になるのか

ここを知らないと、学生は自分の仕事がどうやってお金になり、給与になるのかが分かりません。映像のお金の流れは、大きく4つに分けられます。

| 分野 | お金の出どころ | 流れ | 作り手が受け取るもの |
| --- | --- | --- | --- |
| **広告** | 商品を売りたい企業（クライアント） | クライアント → 広告代理店 → 制作会社 → CG・ポスプロ会社 | 案件ごとの制作費 |
| **アニメ・映画** | 製作委員会に出資する複数の企業（出版社、放送局、配給会社、配信会社など） | 出資者 → 製作委員会 → 元請の制作会社 → 下請の制作会社・個人 | 制作費。権利を持たない限り、ヒットしても分配は受けにくい |
| **ゲーム** | パブリッシャー（発売元） | パブリッシャー → 開発会社 → 外部のCG・ムービー制作会社 | 開発費・外注費 |
| **配信** | 配信サービスの会員の月額料金 | 会員 → 配信サービス → 作品の権利者・制作会社 | 配信権の対価、オリジナル作品の制作費 |

### 権利を持つ側と、作業を請け負う側

この表で一番大事なのは、お金を生み続けるのは「権利」だということです。作品がヒットしたとき、配信、商品化、海外展開、続編からお金を得るのは、出資して権利を持っている側です。一方で、制作会社や個人の多くは、決められた制作費で作業を請け負っています。どれだけ作品が売れても、請け負った側に入るお金は、基本的に最初に決まった制作費です。

### 給与はどこから出ているのか

会社員なら、給与は会社が受け取った制作費の中から、人件費として支払われています。フリーランスなら、1カットいくら、1案件いくらという単価で受け取ります。つまり、自分の仕事の値段は、その案件の予算の中で決まっています。

僕の会社のようなCGプロダクションも、この流れの中にいます。広告の仕事なら代理店や制作会社から、アニメやゲームの仕事なら元請やパブリッシャーから依頼を受け、その制作費でスタッフの給与を払っています。

### だから、構造を知る

自分の1カットが、どの案件の、どの予算の中にあり、そのお金が誰から来ているのか。それを知っていれば、自分の仕事の価値を説明できるようになります。そして、作業を請け負う側にとどまるのか、企画や権利に近い側に回るのかを、自分で選べるようになります。構造を知らないまま手だけを動かしていれば、やはり振り回される側のままです。

## 7. 学生が入っていくのは、その流れの中

学生たちは、卒業すればこの流れの中に入っていきます。アニメの制作会社、ゲーム会社、CGプロダクション、広告の制作会社。どこに就職しても、自分の仕事は誰かの企画と予算と戦略の一部になります。世界の主なスタジオは[世界のビジュアルスタジオ](#studios)のページにまとめています。

自分の手がける1カットが作品全体のどこに位置し、その作品が企業のどんな戦略の中にあり、どんな時代の空気に応えているのか。僕が書籍で「求めること」と「求められること」の両方を書いたのも、同じ理由です。自分が作りたいものと、社会が求めているもの、そしてお金の流れ。その3つが重なる場所でしか、作り手は食べていけません。

学生は、決して安くない学費を払ってこの学校に来ています。甘いだけのものを味わい続け、観る側のまま卒業するなら、そのお金はドブに捨てたのと同じです。払った対価で手に入れるべきなのは、人の心に残る作品を設計できる目と技術、そして自分がどこで価値を生んでいるのかを説明できる知識です。

## 8. だから、僕の授業では

環境そのものは変えられません。だから授業の中にだけ、あえて昔の不便さを戻しています。

- 本編は一度しか観ません。止めない、戻さない、飛ばさない
- 観る前に「何が起きると思うか」を書き、観たあとに予想とのズレを書く
- 分析シートに正解はありません。見ているのは、自分の言葉で理由を書けたかどうかです
- 作品ごとに、作り手の経歴、生まれた時代、企業の戦略、お金の流れまで調べます
- 授業で出た気づきはブログに載せます。それが、最初に投げる小さな石になります

## 結び

シークバーを、ただ通り過ぎないこと。画面の向こうにある作り手の判断と、その作品を生んだ時代とお金の流れを見つけること。そして、自分の石を手に取って投げること。2年間の映像概論でやりたいのは、結局のところ、それだけです。
