# 企画書を、人に渡せる形にする

**今日観た作品**

各自の自主制作の企画書

**宿題**

講評でもらった意見を3つ書き出し、どれを取り入れるかを決める

**次回**

構成案・コンテ・ルックの提出（1）『攻殻機動隊』

**この記事の結論**　企画書は、自分のためのメモではなく、人を巻き込むための道具です。読んだ人が、何を作るのか、なぜ作るのか、どう作るのかを分かれば、協力してくれる人が現れます。

（図：figures/lessons/51-image.svg）
図1　企画書は、人を巻き込むための道具です。

自主制作の企画書を提出し、一人ずつ講評しました。2年前期から作ってきた設計書を、人に渡せる一冊にまとめています。

## この回で考えたこと

### 1. 企画書の構成

芯（誰に、何を、なぜ）、構成とテンションカーブ、コンテの山場、カラースクリプト、素材リストと仕上げの方針。この順番で並べると、読む人が迷いません。

### 2. 抽象から具体へ

企画書は、はしごを上から下へ降ろす順番で書きます。抽象から始めて、最後はパラメータまで。読む人が、自分の作業まで見えるようにします。

### 3. 講評は石の波紋

企画書を人に見せるのは、最初に石を投げることです。返ってきた意見は波紋です。全部を取り入れる必要はありません。どれを取り入れるかを、自分で選んでください。

## 権利の基礎チェック

企画書を人に渡す前に、使う素材の権利を確かめておきます。作品が完成してから「この音楽は使えない」と分かると、作り直しになります。プロの現場では、これは企画の段階で必ず確認することです。

| 素材 | 確認すること |
| --- | --- |
| **音楽** | 市販の曲は、作曲者や演奏者に権利があります。授業内の上映と、ネットでの公開では扱いが変わります。フリー素材を使うときは、利用規約（クレジット表記、商用利用、改変の可否）を読む |
| **映像・写真・イラスト** | 人の作品をそのまま使わない。参考にするのは構図や考え方までで、素材そのものを切り貼りしない |
| **フォント** | フォントにもライセンスがあります。無料のフォントでも、商用利用や動画での使用に条件があることがある |
| **人物・ロゴ・キャラクター** | 実在の人を撮るときは本人の許可を取る。企業のロゴや既存のキャラクターは、無断で使わない |
| **生成AI** | 使ったサービスの規約で、作ったものをどこまで使えるかを確認する。既存の作品に似すぎていないかを自分の目で確かめる（[第56回](#lesson-56)） |
| **自分の作品の権利** | 授業で作った作品をポートフォリオやSNSに載せてよいか、学校の決まりを確認する。チームで作った作品は、全員の了解を取る |

**オマージュと盗用の違い**　第28回の『ラ・ラ・ランド』は、『シェルブールの雨傘』の色づかいや形式を引き継ぎながら、自分の物語と自分の街で作り直していました。考え方や様式を受け継ぐのがオマージュで、他人の素材や表現をそのまま持ってくるのが盗用です。迷ったら、「何を受け継ぎ、何を自分で作ったか」を言葉で説明できるかを確かめてください。

この表は授業での基本の確認項目で、法律の助言ではありません。具体的な判断が必要なときは、学校や専門家に確認してください。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 進め方と講評の観点を伝える |
| 0:10〜1:30 | 企画書の発表と講評 |
| 休憩 | — |
| 2コマ目 0:00〜1:00 | 企画書の発表と講評の続き |
| 1:00〜1:15 | 全体講評 |
| 1:15〜1:30 | 次の目標を書く |

1人5分（発表3分＋質疑2分）で約30人分。人数が少ない場合は、他の人の作品や分析シートを分析シートで読み合う時間に充てます。

**この回の演習**

発表を聞きながら、他の人の発表から引き出しノートに使えるものを3つ集める

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 講評で、一番刺さった意見は何でしたか。
2. その意見を取り入れると、企画の芯はぶれますか。
