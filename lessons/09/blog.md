# 35人で作ったゴジラは、音でどう大きくなったか　『ゴジラ-1.0』

**今日観た作品**

『ゴジラ-1.0』（本編上映）

**宿題**

好きな映画のワンシーンを「音だけ」で聴き、聞こえた音をすべて書き出す

**次回**

音と音楽（後編）：音楽と源流

**この記事の結論**　映像の「大きさ」や「重さ」の半分は音が作っています。『ゴジラ-1.0』は35人のVFXチームで610カットを作った作品ですが、観客が感じる巨大さは画だけでは生まれていません。足音、水の音、そして音が消える瞬間が、画面に映っていないものまで観客に想像させています。

第9回と第10回は「音と音楽」です。題材は、2023年公開の『ゴジラ-1.0』です。CGを学ぶ学生にとっては、少人数のチームでアカデミー視覚効果賞を獲った作品として、映像面でも重要な一本です。前編では効果音や静寂などの「音」、後編では「音楽」を扱います。

## 作り手のバックボーン

**山崎貴（監督・脚本・VFX）**　VFXの現場から監督になった人物で、『ALWAYS 三丁目の夕日』シリーズなどで知られます。本作では監督とVFXスーパーバイザーを兼ね、アカデミー視覚効果賞を受賞しました。監督がこの賞を獲ったのは、『2001年宇宙の旅』のスタンリー・キューブリック以来とされています。

**白組**　山崎が所属するVFX・CGの制作会社です。調布スタジオの35人が、ひとつの大部屋で作業したと報じられています。ハリウッドの大作と比べると、ごく小さなチームです。

## 音を分解する

| 音の種類 | 意味 | 授業で探した例 |
| --- | --- | --- |
| **効果音** | 画面の中で鳴っている音 | 足音、建物の崩れる音、水の音 |
| **環境音** | 場所の空気を伝える音 | 海、風、街のざわめき |
| **台詞** | 登場人物の声 | 叫び、指示、ささやき |
| **静寂** | 音を止めること | 大きな出来事の直前の「間」 |
| **音楽** | 画面の外から鳴る音 | 第10回で扱う |

**あわせて知りたい作り手**

### 渋谷紀世子VFXディレクター

『ゴジラ-1.0』のVFXディレクターで、山崎貴監督らとともにアカデミー視覚効果賞を受賞したチームの一人です。35人のチームで610カットを仕上げた現場の中心にいました。

## 考察：比較から何が言えるか

### 1. 巨大さは、画と音の掛け算で生まれる

画面に映るゴジラの大きさは、カメラとの距離や周囲の建物との比較で伝わります。しかし「重さ」や「近さ」は、足音や地面の振動、水の音で補われています。音を消して同じ場面を観ると、迫力が大きく落ちることを授業で確認しました。

### 2. 音を止めると、観客は身構える

大きな出来事の直前に音が引くと、観客は次に何かが来ると感じて身構えます。静寂は「何もない時間」ではなく、テンションカーブを作るための演出です。

### 3. 少人数のVFXを支えるのは、何を見せないかの判断

35人で610カットを作るには、すべてを画で見せることはできません。音や画面外の気配で想像させる部分を作ることは、限られた資源で迫力を出す方法でもあります。自主制作の規模で映像を作るときにも、そのまま使える考え方です。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：今回の観点を伝え、「観る前の予想」を書く |
| 0:10〜 | 本編上映（止めない・戻さない・飛ばさない） |
| 休憩 | 構成の区切りで休憩。前半で気づいたことを1行メモ |
| 2コマ目 | 上映の続き |
| 上映後 15分 | 分析シート「たどる面」を個人で記入 |
| 15分 | ペアで「授業で投げた問い」を話し合う |
| 15分 | 解説（この記事の考察） |
| 5分 | 引き出しノートに3つ、降ろす欄を記入 |

上映時間が長い場合は、ペアの話し合いを短くして解説の時間を確保します。

**この回の演習**

一番心が動いた場面を1つ選び、はしごを下からたどる。そのうえで、降ろす面を書く

降ろす面：この時期は「形容詞まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. ゴジラが画面に映っていないのに「いる」と感じた場面はどこですか。何がそう感じさせましたか。
2. 音が消えた瞬間はどこにありましたか。その直後に何が起きましたか。
3. 宿題の「音だけ」で聴いた場面で、画では気づかなかった音はありましたか。
