# 山が何度も来る映画のカーブを描く　『ダークナイト』後半

**今日観た作品**

『ダークナイト』後半

**宿題**

前後半を通したテンションカーブを描いてくる

**次回**

台本構成とテンションカーブ（3）演習

**この記事の結論**　『ダークナイト』のテンションカーブは、山が何度も来るギザギザの形をしています。第12回で描いた『ルックバック』の、長い谷から一つの大きな山へ向かう形とは正反対です。カーブの形は、作品が観客にどんな体験をさせたいかを表しています。

前回の続きで、後半を観ました。前後半を通したテンションカーブを、全員で描いて比べました。

## 考察

### 1. ギザギザのカーブは、観客を休ませない

山が何度も来るので、観客は緊張を解く暇がありません。悪役が「秩序が壊れる瞬間」を欲しがっている映画なので、観客も同じように落ち着かない状態に置かれています。

### 2. 谷がないと、山は低く見える

ただし、山ばかりだと観客は疲れてしまいます。この映画にも短い谷はあります。第12回で話した「谷の長さが山の高さを決める」は、ここでも当てはまります。

### 3. カーブは、企画の段階で描く

自主制作では、コンテに入る前にテンションカーブを描いてください。どこに山を置くかを決めてから場面を作ると、構成が迷いません。
