# 悪役が、物語の構造を壊しにくる　『ダークナイト』の構成

**今日観た作品**

『ダークナイト』前半（152分のため2回に分けて上映）

**宿題**

主人公と悪役、それぞれが「何を欲しがっているか」を1行ずつ書く

**次回**

台本構成とテンションカーブ（2）

**この記事の結論**　『ダークナイト』は、悪役のジョーカーが、物語の構造そのものを揺さぶり続ける映画です。普通の映画なら終わるはずの場面で終わらず、山が何度も来る。構成の型を知っているからこそ、型を裏切る構成が作れます。

今回から3回は、台本構成とテンションカーブを2000年代の作品で扱います。1年前期の第11〜12回で『ルックバック』の構成とカーブを描きました。今回は、上映時間が152分ある長編で、その構造を分解します。

## 作り手のバックボーン

**クリストファー・ノーラン（監督・脚本）**　『メメント』で時間の構成をいじる映画を作り、のちに『インセプション』『オッペンハイマー』を撮る監督です。構成そのものを仕掛けにする作り手です。

**ハンス・ジマー（音楽）**　第7〜8回の『DUNE』の音楽も手がけた作曲家です。2000年代から2020年代まで、大作映画の音を作り続けています。

**あわせて知りたい作り手**

### キャスリン・ビグロー監督

『ハート・ロッカー』（2009）で、女性として初めてアカデミー監督賞を受賞した監督です。緊張が途切れない構成は、『ダークナイト』と並べて観る価値があります。

## 考察

### 1. 主人公と悪役の「欲しいもの」

主人公は街の秩序を、悪役は秩序が壊れる瞬間を欲しがっています。二人の欲しいものが正反対だから、物語が前に進み続けます。構成の土台は、登場人物が何を欲しがっているかです。

### 2. 終わりそうで終わらない

普通の映画なら、悪役を捕まえたところで山場を迎えます。この映画は、捕まえたところからさらに状況が悪くなります。観客の「ここで終わるだろう」という予想を、構成で裏切っています。

### 3. 152分を2回に分ける理由

1年生のときに決めた通り、通し鑑賞は2時間前後が上限です。長い作品は、構成の区切りで分けて観ます。どこで分けるかを考えることも、構成を読む練習です。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：作品の背景と、前後半に分ける位置を伝える |
| 0:10〜 | 前半を上映（止めない・戻さない・飛ばさない） |
| 休憩 | — |
| 2コマ目 | 前半の上映の続き（構成の区切りまで） |
| 上映後 20分 | 分析シート「たどる面」を前半分だけ記入。テンションカーブを途中まで描く |
| 20分 | 解説（前半の考察） |
| 5分 | 後半で何が起きるかを予想して書く |

長編のため2回に分けて上映します。分ける位置は構成の区切りで決めます。

**この回の演習**

前半のテンションカーブを途中まで描き、後半の予想を書く

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。
