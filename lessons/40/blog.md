# CGの世界に、カメラを持ち込む　『アバター』のバーチャルカメラ

**今日観た作品**

『アバター』前半（長編のため2回に分けて上映）

**宿題**

CGだと分かっていても本物に見えた場面を3つ書く

**次回**

レイヤー構造（2）パフォーマンスキャプチャ

**この記事の結論**　『アバター』は、CGの世界の中に、監督が手に持って動かせるカメラを持ち込みました。CGの世界を、実写と同じ感覚で撮影する。その発想が、CGの画にカメラマンの呼吸を与えています。

今回から3回はレイヤー構造です。2009年の『アバター』は、CGと実写の境界を大きく動かした作品です。1年後期の第19回『ゼロ・グラビティ』の4年前に、この流れは始まっていました。

## 作り手のバックボーン

**ジェームズ・キャメロン（監督）**　『ターミネーター2』『タイタニック』で、CGの使い方を何度も変えてきた監督です。技術が追いつくまで企画を温め、技術ができてから作る、という作り方をしています。

## 考察

### 1. CGの世界にカメラマンの呼吸を入れる

CGのカメラは、数値で動かすとなめらかすぎて機械的になります。監督が手で持って動かすことで、実写のような揺れや迷いが生まれます。CGに「人が撮った感じ」を入れる工夫です。

### 2. 技術ができるまで待つ

キャメロンは、作りたい映像に技術が追いつくまで企画を待ちました。企画と技術の順番の、一つの答えです。第1回で話した「技術の選択は、作りたいものから逆算される」の極端な例です。

### 3. 立体上映という体験

この作品は、立体映像で観ることを前提に設計されています。見せ方の前提が変わると、構図の作り方も変わります。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：作品の背景と、前後半に分ける位置を伝える |
| 0:10〜 | 前半を上映（止めない・戻さない・飛ばさない） |
| 休憩 | — |
| 2コマ目 | 前半の上映の続き（構成の区切りまで） |
| 上映後 20分 | 分析シート「たどる面」を前半分だけ記入。テンションカーブを途中まで描く |
| 20分 | 解説（前半の考察） |
| 5分 | 後半で何が起きるかを予想して書く |

長編のため2回に分けて上映します。分ける位置は構成の区切りで決めます。

**この回の演習**

前半のテンションカーブを途中まで描き、後半の予想を書く

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。
