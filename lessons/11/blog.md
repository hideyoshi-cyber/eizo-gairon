# 58分の映画は、なぜ58分なのか　『ルックバック』の構成

**今日観た作品**

『ルックバック』（本編上映）

**宿題**

『ルックバック』の場面を、思い出せる順に10個書き出してくる

**次回**

脚本構成（後編）：テンションカーブ

**この記事の結論**　映画の長さは、伝えたい物語の大きさで決まります。『ルックバック』は、読み切り漫画を引き伸ばさず、58分という短い尺で映画にしました。必要な場面だけで構成し、同じ構図を繰り返すことで、二人の時間の流れと関係の変化を観客に体感させています。

第11回と第12回は脚本構成です。題材は、藤本タツキの読み切り漫画を劇場アニメにした『ルックバック』です。上映時間が58分なので、1コマ目で通して観て、2コマ目でじっくり構成を分解しました。物語の中に衝撃的な出来事が含まれるため、上映前にそのことを伝えています。

## 考察：比較から何が言えるか

### 1. 尺は「物語の大きさ」に合わせて決める

多くの劇場映画は2時間前後ですが、本作は58分です。読み切り漫画の物語を2時間に引き伸ばせば、描かなくてよい場面が増え、密度は下がります。尺を物語に合わせるという判断も、脚本構成の一部です。

### 2. 同じ構図の繰り返しが、時間を語る

机に向かう背中の画が何度も繰り返されます。同じ構図の中で、季節や部屋の様子、体の大きさが少しずつ変わることで、セリフなしに年月の経過が伝わります。タイトルの「ルックバック」とも重なるモチーフです。

### 3. 物語の中の「4コマ漫画」は構成の最小単位

二人をつなぐのは4コマ漫画です。起・承・転・結の4コマは、物語構成の最小の型でもあります。この作品自体も、出会い・共作・分岐・再起という大きな4つの段階で読むことができます。

### 4. 声優が初挑戦の俳優を起用した意味

主演の二人はどちらも俳優で、声優は初めてでした。整いすぎない声の芝居は、子どもから大人になる二人の等身大の感じを支えています。キャスティングも、作品の質感を決める設計の一つです。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：今回の観点を伝え、「観る前の予想」を書く |
| 0:10〜 | 本編上映（止めない・戻さない・飛ばさない） |
| 休憩 | 構成の区切りで休憩。前半で気づいたことを1行メモ |
| 2コマ目 | 上映の続き |
| 上映後 15分 | 分析シート「たどる面」を個人で記入 |
| 15分 | ペアで「授業で投げた問い」を話し合う |
| 15分 | 解説（この記事の考察） |
| 5分 | 引き出しノートに3つ、降ろす欄を記入 |

上映時間が長い場合は、ペアの話し合いを短くして解説の時間を確保します。

**この回の演習**

一番心が動いた場面を1つ選び、はしごを下からたどる。そのうえで、降ろす面を書く

降ろす面：この時期は「形容詞まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. この物語を4つの段階に分けるとしたら、どこで区切りますか。
2. セリフがないのに時間が流れたと感じた場面はどこですか。何がそう感じさせましたか。
3. もしこの作品が2時間だったら、何が足され、何が失われますか。
