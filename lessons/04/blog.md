# 切らない映画は、編集をどこに隠したか　『1917 命をかけた伝令』

**今日観た作品**

『1917 命をかけた伝令』（本編上映）

**宿題**

映画かアニメのワンシーンを選び、カットの数を数える

**次回**

ショット・カメラ・構図（前編）『トップガン マーヴェリック』

**この記事の結論**　映像は「時間」「フレーム」「編集」の3つでできています。『1917』は全編を2つの連続したショットに見せることで、編集をなくしたように見せました。しかし編集は消えたのではなく、カメラの動きと構図の中に隠されています。切らないことも、編集の判断の一つです。

第4回は、映像を成り立たせる3つの要素、時間・フレーム・編集を扱いました。題材は、全編がほぼ一続きのショットに見える戦争映画『1917 命をかけた伝令』です。「編集がない映画」を観ることで、逆に編集とは何かが見えてきます。

## 映像の3要素

| 要素 | 意味 | 『1917』では |
| --- | --- | --- |
| **時間** | 観客が体験する時の流れ | 主人公の時間と観客の時間を、ほぼ一致させている |
| **フレーム** | 何を画面に入れ、何を外すか | カメラが兵士に付き添い、見えるものを限定している |
| **編集** | ショットとショットのつなぎ | つなぎ目を物陰や暗がりに隠している |

## 作り手のバックボーン

**サム・メンデス（監督）**　デビュー作『アメリカン・ビューティー』でアカデミー賞を受賞し、『007 スカイフォール』『007 スペクター』を手がけました。『スペクター』の冒頭では、すでに長回しの場面に挑戦しています。本作は、第一次世界大戦に従軍した祖父アルフレッドから聞いた「伝令の話」が元になっており、メンデス自身が最も個人的な作品と語っています。

**ロジャー・ディーキンス（撮影）**　メンデスとは『ジャーヘッド』（2005）以来の4度目の組み合わせです。本作では、ARRIと開発した試作段階の小型カメラを使っています。

**リー・スミス（編集）**　つなぎ目を隠す前提で撮影が進んだため、撮影が終わった時点で編集はほぼ完成していたとされます。

**あわせて知りたい作り手**

### テルマ・スクーンメイカー編集

マーティン・スコセッシ監督の作品を長く編集してきた編集者で、『レイジング・ブル』『アビエイター』『ディパーテッド』でアカデミー編集賞を3度受賞しています。切らない映画を観た回だからこそ、「切る」ことを極めた人も知っておいてください。

## 考察：比較から何が言えるか

### 1. 編集は消えたのではなく、隠された

『1917』は実際には一続きで撮られていません。長回しを撮り、物陰や暗がり、カメラの急な動きを利用してつないでいます。観客がつなぎ目に気づかないように設計すること自体が、高度な編集です。

### 2. 切らないとき、フレームが編集の代わりをする

カットで視点を変えられない代わりに、カメラは兵士の前に回り込み、横に並び、背中を追います。カメラの位置と構図が変わることで、普通の映画ならカットで行う「見せる対象の切り替え」をしています。

### 3. 時間を飛ばすには、物語上の理由がいる

本作で一度だけ時間が飛ぶのは、主人公が気を失う場面です。暗転に物語上の理由を与えることで、観客は時間の跳躍を自然に受け入れます。編集点には、それを正当化する理由が必要だということです。

### 4. 源流：70年以上前の「切らない映画」

つなぎ目を隠して一続きに見せる手法には、ヒッチコックの『ロープ』（1948）という古い前例があります。技術はデジタルになっても、「観客に編集を意識させない」という発想は昔からあるものです。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：今回の観点を伝え、「観る前の予想」を書く |
| 0:10〜 | 本編上映（止めない・戻さない・飛ばさない） |
| 休憩 | 構成の区切りで休憩。前半で気づいたことを1行メモ |
| 2コマ目 | 上映の続き |
| 上映後 15分 | 分析シート「たどる面」を個人で記入 |
| 15分 | ペアで「授業で投げた問い」を話し合う |
| 15分 | 解説（この記事の考察） |
| 5分 | 引き出しノートに3つ、降ろす欄を記入 |

上映時間が長い場合は、ペアの話し合いを短くして解説の時間を確保します。

**この回の演習**

一番心が動いた場面を1つ選び、はしごを下からたどる。そのうえで、降ろす面を書く

降ろす面：この時期は「形容詞まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. つなぎ目が隠されていると思った場所を、3つ挙げてください。
2. カメラが兵士の「前」にいるときと「後ろ」にいるときで、感じ方はどう違いましたか。
3. この映画をあえて普通にカット割りしたら、何が失われますか。
