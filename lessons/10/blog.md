# 70年前のテーマ曲が鳴る瞬間　『ゴジラ-1.0』と1954年の『ゴジラ』

**今日観た作品**

『ゴジラ』（1954）（本編上映）  
『ゴジラ-1.0』の主要場面

**宿題**

『ゴジラ-1.0／C』（モノクロ版）を一部観て、カラー版との違いを3つメモ

**次回**

脚本構成（前編）：構成『ルックバック』

**この記事の結論**　映画音楽は、場面の感情を説明するためではなく、観客の感情の向きを決めるために鳴ります。『ゴジラ-1.0』は、新しく書かれたスコアの中で、1954年の第1作から続くテーマ曲を要所に置きました。70年前の音楽が鳴った瞬間、観客は作品の外にある「ゴジラの歴史」まで一緒に受け取ります。

後編では「音楽」を扱いました。題材は引き続き『ゴジラ-1.0』です。あわせて、源流である1954年の第1作『ゴジラ』を本編で通して観ました。この授業で初めて、2020年代の作品から一気に70年前まで遡る回です。

## 作り手のバックボーン

**佐藤直紀（音楽）**　山崎貴監督と長く組んできた作曲家で、『ALWAYS 三丁目の夕日』シリーズなども手がけています。本作のスコアは、海外の映画賞でも作曲部門の候補に挙がりました。

**伊福部昭（1954年版の音楽）**　第1作のテーマ曲を作曲しました。このテーマは、その後のシリーズで繰り返し使われ、「ゴジラの音」として定着しています。

## 音楽の役割を分解する

| 役割 | 意味 |
| --- | --- |
| **感情の方向づけ** | 同じ画でも、音楽で怖さにも悲しさにも見える |
| **テンションの制御** | 盛り上げる、止める、引く |
| **記憶の呼び出し** | 聞き覚えのある曲で、別の作品や時代を思い出させる |
| **場面の接着** | カットをまたいで鳴り続け、場面を一つにまとめる |

## 考察：比較から何が言えるか

### 1. 新しいスコアと古いテーマの役割分担

新しく書かれたスコアは物語の感情を運び、伊福部昭のテーマは要所でだけ鳴ります。テーマが鳴る場面は限られているからこそ、鳴った瞬間の意味が大きくなります。音楽も「どこで使わないか」で効果が決まります。

### 2. 音楽は作品の外の記憶を連れてくる

テーマ曲を知っている観客は、その瞬間に70年分のゴジラ映画を思い出します。第6回の『トップガン』で構図が前作の記憶を呼び起こしたように、音楽も源流とつながる装置になります。

### 3. 白黒の系譜の終着点

モノクロ版『ゴジラ-1.0／C』は、カラーで作った作品を後から白黒にしたものです。第3回の黒澤モード、第8回のジェディ・プライムと並べると、白黒を「後から変換する」か「撮影で決める」かの違いが、1年前期を通して見えてきます。そしてその先には、白黒で撮られた1954年の第1作があります。

## 1年前期のここまでのまとめ

第1回から第10回で、映像の文法（時間・フレーム・編集・カメラ・構図・光・色・音・音楽）をひととおり扱いました。そのたびに、作品の背後に源流がありました。黒澤明、トニー・スコット、伊福部昭。2年後に90年代までたどり着く前に、すでに源流はそれより古い時代にも広がっています。
