# 同じYouTubeにある、二つの設計　YOASOBI『夜に駆ける』から考える

**今日観た作品**

YouTube動画（宿題から1本）  
YOASOBI『夜に駆ける』MV

**宿題**

好きなゲームのムービーかトレーラー1本。「プレイ中と何が違うか」1行

**次回**

ゲームと映像の違い

**この記事の結論**　YouTube動画と映像作品の違いは「公開場所」ではなく「設計の前提」にあります。YouTube動画は「いつでも離脱される」前提で作られ、映像作品は「観客が時間を預けてくれる」前提で作られます。YouTubeから生まれた『夜に駆ける』のMVは、YouTube上にありながら映像作品として設計されています。

第2回では、学生の宿題から選んだYouTube動画と、YOASOBIのデビュー曲『夜に駆ける』のミュージックビデオを比べました。どちらも同じYouTubeで公開されています。それでも作り方の前提がまったく違う、というのがこの回の論点です。

## 宿題から見えたこと：YouTubeは「情報」か「人」で見られる

「なぜ最後まで見たか」を聞くと、多くは「知りたいことがあった」「この人が好き」のどちらかに集まりました。YouTube動画の多くは、情報か人で視聴を支える設計になっています。話者が画面の中心にいて、要点はテロップで繰り返されます。これは手抜きではなく、いつ閉じられてもおかしくない環境に合わせた、合理的な設計です。

## 4つの違い

|  | YouTube動画 | 映像作品 |
| --- | --- | --- |
| **前提** | いつでも離脱される | 観客が時間を預けてくれる |
| **掴み** | 冒頭数秒で引き止める | 全体のテンションカーブで引っ張る |
| **伝え方** | 話者・テロップ中心 | 画と構成で語る |
| **単位** | チャンネルで継続視聴 | 1本で完結 |

## 作り手のバックボーン

**Ayase（作詞・作曲）**　ボーカロイドの楽曲制作者として活動していました。YOASOBIは、ソニー・ミュージックが運営する小説投稿サイトの作品を音楽にする企画として2019年に始まり、Ayaseが作曲を担っています。

**ikura（ボーカル）**　シンガーソングライターとして活動していたところを、ボーカルとして迎えられました。

**藍にいな（MVアニメーション）**　東京藝術大学デザイン科の出身で、在学中にこのMVを手がけています。原作小説の世界を、限られた色と動きで画にしています。

## 考察：比較から何が言えるか

### 1. 区別するのは「公開場所」ではなく「作り方」

『夜に駆ける』のMVはYouTubeで公開されていますが、話者もテロップもなく、画と音と構成だけで約4分を引っ張ります。YouTubeにあるからYouTube動画、ではありません。どちらの前提で設計されているかで区別する必要があります。

### 2. 小説→曲→映像という「翻訳」の層

この作品は、短編小説を曲にし、その曲を映像にしています。原作の物語は、歌詞で一度抽象化され、MVで再び具体的な画になります。プリプロダクションで「何を残し、何を捨てるか」を決める作業の、よい実例です。

### 3. 同じ曲に、もう一つの設計があった

YOASOBIの名前が広く知られるきっかけになったのは、2020年5月にYouTubeチャンネル「THE FIRST TAKE」で公開された一発撮りの歌唱映像でした。こちらは演者を正面から捉え、編集をほとんど加えない設計です。同じ曲が、作り込まれたMVと、編集を削ぎ落とした歌唱映像という、正反対の二つの設計で届いています。

### 4. 見る環境が変われば、作り方も変わる

90年代、映像はテレビかレンタルビデオで、時間を決めて座って見るものでした。今はスマホで、隙間時間に、いつでもやめられる環境で見られます。設計の違いは、作り手の好みではなく、視聴環境への適応です。この話は、2年後に90年代までたどり着いたときに改めて扱います。

## テロップは「情報デザイン」

YouTube動画のテロップは、飾りではなく情報を確実に届けるためのデザインです。テレビの画面デザインの基礎は [ayato@web の TV DESIGN](https://www.ayatoweb.com/tvd.html) にまとまっています。

## MVが広告になるとき：マクドナルド「ティロリミックス」

YOASOBIの曲は、MVの外にも広がっています。その一つが、日本マクドナルドの「ティロリミックス」です。ポテトが揚がったときに鳴る「ティロリ♪」という音を、人気アーティストの曲とマッシュアップ（2つ以上の曲を混ぜて別の曲にする手法）した企画で、毎年MVが作られています。

|  | 2023年 | 2024年 |
| --- | --- | --- |
| **曲** | Ado「踊」× asmi「PAKU」×「ティロリ♪」音 | YOASOBI「群青」× Vaundy「花占い」×「ティロリ♪」音 |
| **公開** | 2023年1月13日、マクドナルド公式YouTube | 2024年1月11日11時1分（ポテトの形の「1」揃い）、期間限定公開 |
| **映像** | 2つの曲のMVのキャラクターを3DCGにして、近未来のマクドナルドの店舗で歌い踊る | アーティストを夢見る若者を、ポテトをモデルにした「ポテト3兄弟」が応援する物語 |
| **作り方** | Unreal Engine 5を中心にした制作の流れ。コマ撮りのような動きのルック | キャラクターデザインはAcky Bright、コンセプトアートはWACHAJACK。アニメーションはMaya、背景はUnreal Engineで作り、データを行き来させる仕組みを作った |

出典：日本マクドナルドの発表、ADVERTIMES、CGWORLDの制作記事をもとに要約しています。MVは期間限定公開のため、授業の時点で観られるかを確認してください。

### 1. MVであり、ショートムービーであり、CMでもある

2024年版を手がけた電通のクリエイティブディレクターは、この映像を「ミュージックビデオであり、ショートムービーでもあり、ブランドCMでもある」と語っています。今日の授業で引いた「YouTube動画」と「映像作品」の境界線に、さらに「広告」という軸が重なっている例です。

### 2. お金の出どころが変わると、MVの設計も変わる

普通のMVはレコード会社やアーティストの側がお金を出します。ティロリミックスは、お金を出しているのはマクドナルドです。だから、曲を伝えるだけでなく、ブランドの「音」を記憶させ、店舗のポップアップイベントにまでつながる設計になっています。[はじめに読む](#essay-01)で話したお金の流れが、1本のMVの中に見えます。

### 3. 物語のテーマは「作ろうとしてもがく若者」

2024年版のコンセプトは、何かを作ろうとしてもがいている若者の背中を押すことでした。広告でありながら、物語の芯は作り手を目指す皆さんそのものです。お金の出どころが広告主でも、人の心に残るのは、ちゃんと芯のある物語です。

### 4. 作っているのは、皆さんが入っていく会社

コンセプトアートを担当したWACHAJACKは、[世界のビジュアルスタジオ](#studios)で紹介したKASSENの立ち上げメンバーが共同で設立した会社です。CGはMaya、背景はUnreal Engineという、皆さんが授業で触れているツールで作られています。
