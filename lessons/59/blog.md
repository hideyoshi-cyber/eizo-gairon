# 波紋を読んで、次の石を選ぶ

**今日観た作品**

上映した全員の自主制作

**宿題**

講評を受けて、次に作りたい作品の芯を20文字以内で書く

**次回**

2年間の総括

**この記事の結論**　講評は、作品の点数をつける場ではありません。投げた石の波紋を、全員で読む場です。波紋を読めば、次にどんな石を、どこに投げればいいかが見えてきます。

上映会で観た作品を、一人ずつ講評しました。他の人が書いた分析シートも本人に渡しています。

## この回で考えたこと

### 1. 他人の分析シートを受け取る

自分の作品が、他の人にどう読まれたかが分かります。はしごの4段で、どこまで伝わっていたかを確かめてください。

### 2. 伝わらなかったところが、次の課題

伝わらなかった部分は、どこかの段を飛ばしていた可能性があります。抽象から形容詞、具体、パラメータ。どこで途切れたかを探してください。

### 3. 次の石を選ぶ

3年生の卒業制作では、今回よりも大きな石を投げることになります。今回の波紋を読んで、次に何を作るかの芯を決めてください。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 進め方と講評の観点を伝える |
| 0:10〜1:30 | 講評と、他の人の分析シートの受け渡し |
| 休憩 | — |
| 2コマ目 0:00〜1:00 | 講評と、他の人の分析シートの受け渡しの続き |
| 1:00〜1:15 | 全体講評 |
| 1:15〜1:30 | 次の目標を書く |

1人5分（発表3分＋質疑2分）で約30人分。人数が少ない場合は、他の人の作品や分析シートを分析シートで読み合う時間に充てます。

**この回の演習**

発表を聞きながら、他の人の発表から引き出しノートに使えるものを3つ集める

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 他の人の分析シートで、一番意外だった読まれ方は何ですか。
2. 次に作りたい作品の芯を、20文字以内で言ってください。
