# 周期表がアパートに見えた日　『マイ・エレメント』の世界のルール

**今日観た作品**

『マイ・エレメント』（本編上映）

**宿題**

身の回りのものを1つ選び、それが住人になった街の「ルール」を3つ考えてくる

**次回**

世界観の作り方（後編）：ビジュアル

**この記事の結論**　世界観とは、見た目の前に「ルール」です。『マイ・エレメント』は、火・水・土・風という元素の性質から、住む場所、移動、食べ物、住人どうしの摩擦までを決めています。そしてそのルールの土台には、監督自身の移民の家族の記憶がありました。説得力のある世界は、作り手の個人史から生まれます。

（図：figures/lessons/13-image.svg）
図1　周期表のマス目がアパートに見えたことが、この作品の世界観の出発点でした。

第13回と第14回は「世界観の作り方」です。題材は、ピクサーの『マイ・エレメント』です。火の娘エンバーと水の青年ウェイドが出会う物語で、世界そのものが元素のルールで設計されています。前編ではルール、後編ではビジュアルを扱います。

## 作り手のバックボーン

**ピーター・ソーン（監督）**　カリフォルニア芸術大学を卒業し、2000年にピクサーに入社しました。アートとストーリーの部署で『ファインディング・ニモ』などに携わり、『アーロと少年』で長編監督を務めています。

**着想の原点**　中学の理科の授業で周期表を見たとき、それがアパートの建物に見えたことが、この作品の種になったと語っています。

**家族の物語**　両親は1970年代に韓国からニューヨークへ移り住み、ブロンクスで食料品店を営みました。作中のエンバーの家の店は、その店がモデルです。約7年の制作期間の間に、両親はどちらも亡くなっています。ソーン監督は、この映画を「両親に感謝し、その犠牲を理解する」物語だと語っています。

## 世界のルールを分解する

| 観点 | 作品の中のルール（授業での観察） |
| --- | --- |
| **住む場所** | 元素ごとに暮らしやすい地区があり、街の作りが元素の性質に合わせてある |
| **移動** | 水の多い街で、火の住人は移動にも気をつけなければならない |
| **社会** | 街は水の住人を中心に作られており、火の住人には住みにくい |
| **関係** | 火と水は触れ合うことができない、という制約が恋愛の障害になる |

**あわせて知りたい作り手**

### ドミー・シー監督

ピクサーの『私ときどきレッサーパンダ』（2022）の監督です。ピクサーの長編で、女性が一人で監督を務めた最初の作品になりました。短編『Bao』ではアカデミー短編アニメーション賞を受賞しています。

## 考察：比較から何が言えるか

### 1. ルールは「性質」から導く

ソーン監督は、特定の文化をそのまま描くと戯画になってしまうため、元素そのものの性質から文化を作ることを目指したと語っています。燃える、流れる、育つ、漂う。性質から暮らし方を導くことで、どの観客にも通じる普遍的な世界になっています。

### 2. ルールは物語の障害になる

「火と水は触れ合えない」というルールは、そのまま二人の関係の障害になります。世界観のルールは飾りではなく、物語を動かす装置として設計されています。

### 3. 説得力の源は作り手の個人史

移民の街、家族の店、親の期待。作品の世界は、監督が生きてきた現実を元素に置き換えたものです。第1回の坂口博信、第4回のサム・メンデスと同じく、作り手の個人的な経験が作品の背骨になっています。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：今回の観点を伝え、「観る前の予想」を書く |
| 0:10〜 | 本編上映（止めない・戻さない・飛ばさない） |
| 休憩 | 構成の区切りで休憩。前半で気づいたことを1行メモ |

| 15分 | ペアで「授業で投げた問い」を話し合う |
| 15分 | 解説（この記事の考察） |
| 5分 | 引き出しノートに3つ、降ろす欄を記入 |

上映時間が長い場合は、ペアの話し合いを短くして解説の時間を確保します。

**この回の演習**

一番心が動いた場面を1つ選び、はしごを下からたどる。そのうえで、降ろす面を書く

降ろす面：この時期は「形容詞まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 作品の中で見つけた「この世界のルール」を3つ挙げてください。
2. そのルールは、物語のどこで障害として働いていましたか。
3. この世界に「電気」の住人がいたら、どんなルールが加わりますか。
