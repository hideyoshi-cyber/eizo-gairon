# 2年前に観たオープニングを、もう一度観る　『FF7』（1997）

**今日観た作品**

『FF7』（1997）のオープニングと冒頭のプレイ映像（第1回と同じ映像）

**宿題**

1年前期の第1回の分析シートを読み返し、今の自分ならどう書くかを書く

**次回**

生成AIと作り手

**この記事の結論**　2年前、第1回で観たFF7のオープニングを、もう一度観ました。同じ映像なのに、見えるものがまったく違うはずです。レイヤーの継ぎ目、カメラの位置、色、音。変わったのは映像ではなく、皆さんの目です。

（図：figures/lessons/55-image.svg）

中間講評の前に、第1回で観た映像に戻りました。2年かけて今から遡ってきた旅は、ここで出発点とつながります。

## 考察

### 1. 同じ映像、違う目

第1回では「かっこいい」「古い」で止まっていた人も多かったはずです。今は、どこが継ぎ目で、なぜそこに置いたのかが見えるはずです。

### 2. 第1回のシートと比べる

第1回の分析シートを読み返してください。空欄だった項目が、今は書けるはずです。書けるようになったことが、2年間で手に入れた筋肉です。

### 3. 自分の作品にも同じ目を

この目で、自分の自主制作を観てください。他人の作品の継ぎ目が見えるなら、自分の作品の継ぎ目も見えるはずです。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：「カメラを持つのは誰か」という観点を伝える |
| 0:10〜0:25 | トレーラー・ムービーシーンを上映 |
| 0:25〜1:30 | プレイ映像を上映（「プレイ画面」の表の順に） |
| 休憩 | — |
| 2コマ目 0:00〜0:20 | 比較シート：ムービーとプレイで、時間とカメラの主導権がどう違うかを書く |
| 0:20〜0:50 | ペアで比較、数名が発表 |
| 0:50〜1:20 | 解説（この記事の考察） |
| 1:20〜1:30 | 引き出しノートに3つ、降ろす欄を記入 |

プレイ映像は実況や解説の声が入っていないものを選び、使う時間の位置を事前に控えておきます。

**この回の演習**

ムービーからプレイに切り替わる瞬間を3つ書き出し、それぞれで何が変わったか（カメラ・音・画質・文字）を書く

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 第1回では見えなかったもので、今見えたものは何ですか。
2. 第1回の分析シートで、今なら書ける項目はどれですか。
