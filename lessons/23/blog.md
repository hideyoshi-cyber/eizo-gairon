# CGに、印刷のズレを描き足す　『スパイダーマン：スパイダーバース』のルック

**今日観た作品**

『スパイダーマン：スパイダーバース』（本編上映）

**宿題**

画面の中で「漫画の印刷みたいだ」と思った部分を3つ探す

**次回**

モーショングラフィックス（2）コマ数の演出

**この記事の結論**　『スパイダーバース』は、3DCGの画面に、わざと漫画の印刷のズレや網点を描き足しました。CGをきれいにする方向ではなく、CGに「手で作った痕跡」を足す方向に進んだ作品です。ルックは技術の限界ではなく、作り手の選択で決まります。

後期のモーショングラフィックスの回は、CGアニメーションの見た目を大きく変えた作品から始めます。CGを学ぶ学生には、技術とルックの関係を考えるのにこれ以上ない題材です。

## 作り手のバックボーン

**フィル・ロード、クリストファー・ミラー（製作）**　『くもりときどきミートボール』『LEGO ムービー』で、CGアニメーションの見た目を毎回変えてきたコンビです。この作品でも、CGアニメの「当たり前の見た目」を疑うところから始めています。

## 考察

### 1. 失敗に見えるものを、表現にする

印刷の色ズレは、本来は失敗です。この作品はそれを、ピントの外れた背景や、画面の奥行きの表現として使っています。欠点をルールに変えることで、新しいルックが生まれています。

### 2. 漫画という源流

網点、集中線、吹き出しの文字。どれも紙の漫画から来ています。CGの作品の源流が、紙の印刷物にあるという例です。

### 3. ルックは選択

CGは、写真のようにリアルにもできるし、手描きのようにもできます。どちらに寄せるかは、技術ではなく作品が何を伝えたいかで決まります。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：今回の観点を伝え、「観る前の予想」を書く |
| 0:10〜 | 本編上映（止めない・戻さない・飛ばさない） |
| 休憩 | 構成の区切りで休憩。前半で気づいたことを1行メモ |
| 2コマ目 | 上映の続き |
| 上映後 15分 | 分析シート「たどる面」を個人で記入 |
| 15分 | ペアで「授業で投げた問い」を話し合う |
| 15分 | 解説（この記事の考察） |
| 5分 | 引き出しノートに3つ、降ろす欄を記入 |

上映時間が長い場合は、ペアの話し合いを短くして解説の時間を確保します。

**この回の演習**

一番心が動いた場面を1つ選び、はしごを下からたどる。そのうえで、降ろす面を書く

降ろす面：この時期は「具体まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 漫画の印刷のようだと感じた部分は、場面のどんな感情と結びついていましたか。
2. この作品を写真のようなリアルなCGで作ったら、何が失われますか。
