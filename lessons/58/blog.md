# 作った作品を、観客の前で上映する

**今日観た作品**

全員の自主制作（上映会）

**宿題**

他の人の作品を1本選び、分析シートで分析する

**次回**

講評

**この記事の結論**　完成上映会は、2年間で初めて「観る側」と「作る側」が入れ替わる日です。自分の作品が観客にどう届くかを、自分の目で確かめてください。それが、自分の投げた石の波紋です。

（図：figures/lessons/58-image.svg）
図1　完成上映会は、「観る側」と「作る側」が入れ替わる日です。

2年間の集大成として、全員の自主制作を上映しました。上映は第1回と同じルールです。止めない、戻さない、飛ばさない。

## この回で考えたこと

### 1. 作り手として観られる

今日は、皆さんの作品が分析シートで読まれる側になります。2年間、他人の作品にしてきたことを、今度は自分の作品がされます。

### 2. 観客の反応を見る

上映中は、画面だけでなく、観ている人の反応も見てください。笑ったところ、息をのんだところ、退屈そうだったところ。それが波紋です。

### 3. 他人の作品を読む

宿題では、他の人の作品を分析シートで読んでもらいます。同じ課題を同じ時間で作った作品だからこそ、判断の違いがよく見えます。

（図：figures/lessons/58-diagram.svg）
図2　観客の反応が、自分の投げた石の波紋です。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 上映のルール（止めない・戻さない・飛ばさない）を確認 |
| 0:10〜1:30 | 全員の自主制作を上映 |
| 休憩 | — |
| 2コマ目 0:00〜1:00 | 上映の続き |
| 1:00〜1:30 | 観客としての感想を1作品ずつ一言で書く |

上映順は事前に決めておき、作品ごとの入れ替え時間を短くします。

**この回の演習**

他の人の作品を1本選び、分析シートで分析する（宿題で仕上げる）

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 自分の作品で、観客の反応が一番大きかったのはどこですか。
2. 予想していた反応と、違ったところはありましたか。
