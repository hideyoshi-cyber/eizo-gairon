# 14回分の目で、自分の1本を読む　前期まとめ発表

**今日観た作品**

各自が選んだ2020年代の作品1本

**宿題**

前期の分析シート15枚を見返し、最初と最後で何が変わったかを3行で書く

**次回**

VFX・合成（1）『シン・ゴジラ』

**この記事の結論**　前期の目標は「見る」から「読む」へ移ることでした。最終回は、各自が2020年代の作品を1本選び、分析シートの6項目で発表します。第1回では半分も埋まらなかったシートが、どこまで埋まるようになったか。それを自分で確かめる回です。

第15回は前期のまとめです。新しい作品は上映せず、各自が選んだ1本を分析シートで発表します。発表の前に、15分の「書籍の章トーク」として、講師の書籍原稿から「センスとコンセプト」の章を紹介しました。

## 発表のフォーマット（1人5分）

1. 作品名と、選んだ理由（30秒）
2. 分析シート6項目のうち、一番書けた項目を詳しく（2分）
3. 一番書けなかった項目と、その理由（1分）
4. この作品の「源流」だと思う作品（1分）
5. 質疑（30秒）

## 講評の観点

成績は出席と感想の提出で決まります。ここに挙げたのは、発表を聞くとき、講評するときに見るポイントです。

| 観点 | 見ているところ |
| --- | --- |
| **読めているか** | 「かっこいい」で終わらず、理由を画・音・構成の言葉で説明できているか |
| **前期の道具を使えているか** | レイヤー構造、テンションカーブ、光と色など、前期の観点を使っているか |
| **源流に触れているか** | 作品の背景にある作り手や過去の作品に目を向けているか |
| **自分の変化を言えるか** | 第1回のシートと比べて、何が書けるようになったか |

## 考察：前期で身につけたこと

### 1. 画面の裏にある「判断」が見えるようになった

カメラを実機に載せる、赤外線で撮る、58分で終える。前期で見てきたのは、どれも作り手の判断でした。映像を読むとは、その判断を見つけることです。

### 2. 源流は思ったより古い

2年間で90年代まで遡る予定でしたが、前期だけで黒澤明、1954年の『ゴジラ』まで源流が広がりました。後期からは2010年代に入り、その間をつないでいきます。

### 3. センスは「選び抜く力」

書籍の章トークで紹介したとおり、センスは生まれつきの才能ではなく、なぜそれを選んだのかを問い続けることで育つ「選び抜く力」です。分析シートは、その問いを習慣にするための道具です。
