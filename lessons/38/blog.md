# 同じ構図を繰り返して、時間を戻す　『時をかける少女』の演出

**今日観た作品**

『時をかける少女』主要場面（再上映）

**宿題**

同じ構図が繰り返される場面を2組見つけ、何が違うかを書く

**次回**

絵コンテ（3）富野由悠季とガンダム

**この記事の結論**　時間を戻る物語では、観客が「同じ場面に戻った」と分かる必要があります。『時をかける少女』は、同じ場所を同じ構図で繰り返し撮ることで、それを説明なしに伝えています。繰り返しの中の小さな違いが、物語を前に進めます。

前回の続きで、構図の繰り返しに注目しました。第11回の『ルックバック』で「同じ構図の繰り返しが時間を語る」と話しました。今回は、その繰り返しを時間を戻す仕掛けとして使っている例です。

## 考察

### 1. 同じ構図は、観客の記憶を呼び出す

同じ構図が出てくると、観客は前の場面を思い出します。だから、時間が戻ったことを説明しなくても分かります。

### 2. 違いが物語を進める

繰り返しの中で、少しずつ何かが違います。その違いに気づいたとき、観客は物語が前に進んだことを知ります。繰り返しと違いは、セットで設計されています。

### 3. コンテの段階で決める

同じ構図を正確に繰り返すには、コンテの段階で構図を決めておく必要があります。描きながら決めていては、繰り返しになりません。

| 0:10〜0:50 | 主要場面を再上映（観点を絞って観る） |
| 0:50〜1:30 | 演習（個人） |
| 休憩 | — |
| 2コマ目 0:00〜0:30 | 演習の続き、ペアで見せ合う |
| 0:30〜0:50 | 数名が発表 |
| 0:50〜1:20 | 解説（この記事の考察） |
| 1:20〜1:30 | 引き出しノートに3つ、降ろす欄を記入 |

作品の本編は前回すべて上映しています。今回は場面を絞って再上映し、手を動かす時間を中心にします。

**この回の演習**

繰り返される構図を2組スケッチし、違いを書き込む

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 見つけた2組の繰り返しで、何が違っていましたか。
2. その違いは、物語の何を伝えていましたか。
