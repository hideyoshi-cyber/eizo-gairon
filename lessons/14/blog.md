# キャラクターそのものがエフェクトになる世界　『マイ・エレメント』のビジュアル設計

**今日観た作品**

『マイ・エレメント』（主要場面を再上映）

**宿題**

自分の世界の「ルール5つ」と「街のスケッチ1枚」を描いてくる（前期まとめ発表の素材）

**次回**

前期まとめ：分析シート発表

**この記事の結論**　ルールが決まると、ビジュアルはそこから導かれます。『マイ・エレメント』では、炎や水そのものがキャラクターなので、エフェクトと演技が同じものになっています。街は実在する運河の都市を参考にしながら、元素の性質に合わせて組み替えられています。世界観のビジュアルは、ルールを画に翻訳する作業です。

後編では、前回の「ルール」がどう画になっているかを見ました。CGを学ぶ学生にとっては、キャラクターとエフェクトの境界がなくなる表現として、技術面でも注目したい作品です。

## ビジュアルの設計を分解する

| 要素 | 作品での扱い（授業での観察を含む） |
| --- | --- |
| **キャラクター** | 炎や水が常に揺らぎ、感情に合わせて形や光が変わる。エフェクトがそのまま演技になっている |
| **街** | コロナ禍の時期に、制作チームはアムステルダムやヴェネツィアなど運河の街をオンラインで取材し、街のデザインに活かした |
| **地区** | ニューヨークのリトルイタリーやコリアタウンのような移民街がもとになっている |

## 考察：比較から何が言えるか

### 1. キャラクターとエフェクトの境界がなくなる

普通のCGアニメでは、キャラクターのアニメーションとエフェクトは別の工程です。この作品では、炎の揺らぎや水の透明感そのものが感情表現になっているため、二つが切り離せません。第1回で見た「レイヤー構造の統合」と同じ流れが、キャラクターの中で起きています。

### 2. 実在の街を参考に、ルールで組み替える

運河の都市という実在の参考を持ちながら、それを元素のルールで組み替えることで、見たことのない、でも信じられる街になっています。リファレンスはそのまま使うのではなく、自分の世界のルールで翻訳して使います。

### 3. 世界観の設計書は、プリプロの中心になる

ルールとビジュアルをまとめた設計書があれば、チームの誰が描いても同じ世界になります。2年前期では、この設計書（ルック、カラースクリプト、ルール）を自分の企画で作ります。宿題の「ルール5つと街のスケッチ」は、その最初の一歩です。
