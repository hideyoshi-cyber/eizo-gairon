# 15秒で、人を動かす　CMという映像の設計

**今日観た作品**

CM集（Apple「1984」、日清カップヌードル「hungry?」、Honda「Cog」、Nike「Write the Future」、マクドナルド「ティロリミックス」ほか）

**宿題**

身近な商品を1つ選び、15秒CMの企画を「誰に・何を・なぜ」の一言と、絵コンテ4カットで描いてくる

**次回**

タイトル・キネティックタイポ（1）『シン・ゴジラ』

**この記事の結論**　CMは、映画やアニメと違って、最初から「お金を出す人」と「解くべき課題」がある映像です。商品を知ってもらう、好きになってもらう、店に来てもらう。その課題を、15秒や30秒の中で解く。はしごの抽象からパラメータまでが、映像の中で一番短い時間に詰め込まれているのがCMです。そして皆さんの多くが、最初に関わるのはこの仕事です。

（図：figures/lessons/20-image.svg）
図1　CMは、15秒や30秒の中で、解くべき課題を解く映像です。

今回は1本の作品ではなく、映像の歴史に残るCMを集めて上映しました。[はじめに読む](#essay-01)の記事で、映像のお金の流れの一番上に「広告」を置きました。今回はその広告が、どんな映像として作られてきたのかを観ます。僕の会社でも、一番多い仕事はCMや広告の映像です。

## 作り手のバックボーン

**中島信也（CMディレクター）**　1959年生まれ。武蔵野美術大学を卒業して東北新社に入り、1983年にCMディレクターとしてデビューしました。日清カップヌードル「hungry?」で1993年のカンヌ国際広告祭グランプリ、サントリー「燃焼系アミノ式」で2003年のACCグランプリ、サントリー「伊右衛門」で2005年のADCグランプリを受賞しています。デジタル技術を使った、見て楽しいCMを作り続けてきた人です。本人は、CMを長く作ってきて分かったことを「すべては人を喜ばせるためにある」と語っています。

**リドリー・スコット（Apple「1984」の監督）**　『エイリアン』『ブレードランナー』の監督で、もともとCMの世界で腕を磨いた人です。第6回のトニー・スコットの兄でもあります。CMと映画の間を行き来する監督の代表です。

## 考察

### 1. CMには「お金を出す人」と「課題」が最初からある

映画やMVは、作り手が作りたいものから始まることがあります。CMは違います。最初に依頼主がいて、売りたい商品があり、解きたい課題があります。作り手の仕事は、その課題を映像で解くことです。自分の作りたいものと、求められているものが重なる場所を探す。僕の書籍で書いた「求めること」と「求められること」が、一番はっきり見える仕事です。

### 2. 15秒に、はしごの全段が詰まっている

ブランドが伝えたいこと（抽象）を、形容詞にし、場面にし、色や秒数やカットのパラメータに降ろす。CMはそれを15秒でやります。尺が短い分、どこかの段を飛ばすと、すぐに「何のCMか分からない」映像になります。

### 3. 長回しの系譜は、CMにもある

Honda「Cog」は、部品が次々に動いていく様子を、切れ目のない映像のように見せています。第4回の『1917』、第19回の『ゼロ・グラビティ』と同じく、「切らない」ことが観客を引きつける力になっています。映画の技法とCMの技法は、行き来しています。

### 4. 映画監督とVFXスタジオが、CMを作っている

リドリー・スコット、イニャリトゥ、そしてThe Mill。世界の一線の作り手が、CMを作っています。CMは映画への遠回りではなく、映像の最前線の一つです。[世界のビジュアルスタジオ](#studios)のページも合わせて見てください。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：CMとほかの映像の違い（お金を出す人と課題） |
| 0:10〜0:50 | CM集を上映（1本ずつ、止めずに観る） |
| 0:50〜1:30 | 1本選んで、「誰に・何を・なぜ」と、はしごの4段を書き出す |
| 休憩 | — |
| 2コマ目 0:00〜0:25 | 解説（この記事の考察） |
| 0:25〜1:10 | 演習 |
| 1:10〜1:30 | 数名が発表し、講評 |

**この回の演習**

身近な商品を1つ選び、15秒CMの企画を「誰に・何を・なぜ」の一言で書き、形容詞3つと場面の指示3つまで降ろす

降ろす面：この時期は「具体まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 上映したCMの中で、一番「課題」がはっきりしていたのはどれですか。その課題は何でしたか。
2. 15秒のCMで、どこまで情報を削っていましたか。
3. CMと分からずに観たら、映画やMVに見える作品はありましたか。
