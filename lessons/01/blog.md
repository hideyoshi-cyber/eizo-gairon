# 27年で何が変わり、何が変わらなかったか　『FF7』と『FF7 リバース』

**今日観た作品**

『FF7』（1997）オープニング  
『FF7 リバース』（2024）トレーラー

**次回**

YouTube動画と映像作品の違い

**この記事の結論**　27年で変わったのは「リアルタイムで描ける範囲」です。変わらなかったのは「ゲームを映画のように語る」という設計思想と、それを担った作り手です。そして技術の選択は、どちらの時代も表現より先に「制約と時間」から決まっています。

映像概論は、2年・60回をかけて2020年代から90年代へ映像を遡る授業です。初回に同じタイトルの1997年版と2024年版を並べたのは、この「遡る」という見方を一度で体験してもらうためです。以下では、両作の作品データと作り手の背景を整理したうえで、比較から何が言えるかを考えます。

## 1997年版：2Dを捨てて3Dに賭けた判断

FF7の企画は1994年、スーパーファミコン向けの2D作品として始まっています。チームは一度『クロノ・トリガー』の開発支援に回り、1995年に議論を再開しました。このとき2Dを続ける安全な道もありましたが、チームは新世代ハードで3Dを作るという、リスクの高い道を選びました。

ハードの選択も、技術の好みではなく制約で決まっています。NINTENDO64での試作では、2,000ポリゴンのモンスター1体でフレームレートが落ちました。カートリッジの価格高騰も、買ってもらえる層を狭めていました。容量の大きいCD-ROMを持つPlayStationへの移行は、表現上の理想というより「作りたいものが入る器」を選んだ結果だと言えます。

体制も当時の常識を超えていました。通常20人程度だったゲーム開発に対し、FF7は100〜150人体制で、SGI Onyxなどの機材とソフトに約2,100万ドルを投じています。多くのスタッフにとって、初めて触る技術だったとされています。

## 作り手のバックボーン

**坂口博信（プロデューサー）**　シリーズの生みの親です。FF3の開発中に母親を亡くした経験から「生命」をテーマに据え、生を描くには死を描く必要があると考えました。これが、物語中盤のヒロインの死という構成につながっています。

**北瀬佳範（ディレクター）**　FF6の共同ディレクターを経て、本作の監督を務めました。映画好きで、映画とゲームの語りの共通点に関心を持っていました。FF7の映画的な演出スタイルは、北瀬によるところが大きいとされています。

**野村哲也（キャラクターデザイン）**　手描きの企画書で坂口の目に留まり、メインキャラクターデザインに抜擢されました。クラウドとセフィロスの関係を宮本武蔵と佐々木小次郎になぞらえて設計し、ヒロインを死なせる案も野村の提案です。

**植松伸夫（音楽）**　強い旋律で作品を定義するのではなく、映画のサウンドトラックのように場面の空気を映す方針を取りました。3D化した映像に対して、主張の強すぎる音楽は合わないと判断したためです。

## 1997年版の映像：二層構造とその継ぎ目

FF7の映像は二層でできています。プリレンダの2D背景の上に3Dキャラクターを重ねるリアルタイム部分と、子会社ビジュアルワークスが制作したCGムービー（FMV）です。ムービー制作には『スター・ウォーズ』『ジュラシック・パーク』『ターミネーター2』の経験者も参加しています。

開発の山場とされたのが、リアルタイムのクラウドがCGムービーの走る列車に飛び乗る場面のように、二つの層を同期させたことです。裏返すと、ムービーとゲーム画面の画質差が目立たないよう環境を作り込むことが、北瀬にとって最も骨の折れる仕事でした。

制約も厳しいものでした。技術デモは400MBを超えるメモリの開発機で作られましたが、PlayStationのメインメモリは2MB、テクスチャ用は500KBしかありません。背景は2枚の2D画像を異なる速度で動かし、奥行きを擬似的に作っています。

## 2024年版：同じ作り手が、役割を変えて戻ってきた

リバースの体制で注目したいのは、1997年の中心人物が役割を変えて残っていることです。北瀬はディレクターからプロデューサーへ、野村はキャラクターデザインからクリエイティブディレクターへ移り、野島はシナリオを書き続けています。そのうえで、ディレクターには次の世代の浜口直樹が立ちました。

技術面では、Unreal Engine 4を使い続けた判断が象徴的です。浜口によれば、開発開始時点でUnreal Engine 5の一部機能はまだ発展途上でした。その完成を待つより、必要な機能を自社で作り、前作で築いたパイプラインを活かす方が早く届けられると判断しています。結果として、リバースは前作から約4年で発売されました。

## 考察：比較から何が言えるか

### 1. レイヤー構造が「工程の分業」から「1つのエンジン」に統合された

1997年版の映像は、プリレンダ背景、リアルタイムの3Dキャラクター、CGムービーという別々の工程の層を重ねて作られていました。演出の課題は、その継ぎ目を観客に意識させないことでした。2024年版ではほぼすべてがリアルタイムで描かれ、継ぎ目そのものが消えています。分析シートの「レイヤー構造」は、画面の層だけでなく、制作工程の層としても読めるということです。

### 2. 変わらないのは「映画のように語る」という設計思想

映画好きの北瀬が持ち込んだシネマティックな語りや、映画音楽のように場面に寄り添う音楽の考え方は、技術が入れ替わっても作品の背骨として残っています。画質の差は誰にでも分かります。本当に読むべきなのは、この変わらない部分です。

### 3. 技術の選択は「何を作りたいか」から逆算される

1997年のPlayStation選択は容量という制約から、2024年のUnreal Engine 4継続は開発期間という制約から決まっています。どちらも最新技術を追いかけたのではなく、作りたいものを期限内に届けるための選択です。これはプリプロダクションそのものであり、自主制作で技術やソフトを選ぶときにも、同じ順番で考えてほしいところです。

### 4. 「源流」は作品だけでなく、人でたどれる

同じ作り手が、27年後に役割を変えて同じ作品に戻っています。分析シートの「源流作品」を書くときは、作品名だけでなく、監督やデザイナーが何を経てきたかを調べてみてください。表現の理由が見えてきます。この授業で毎回、作品データと作り手の背景を整理するのはそのためです。
