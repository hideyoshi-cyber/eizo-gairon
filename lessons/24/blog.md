# 動きを減らして、キャラクターを描く　コマ数という演出

**今日観た作品**

『スパイダーバース』の主要場面（再上映）

**宿題**

好きなアニメの1場面を選び、なめらかな動きと、カクカクした動きを探す

**次回**

アニメの演出（1）『君の名は。』

**この記事の結論**　『スパイダーバース』は、キャラクターや場面によって、1秒間に描き変える絵の枚数を使い分けています。なめらかに動かすことが、いつも正解ではありません。動きの細かさも、感情やキャラクターを伝えるパラメータの一つです。

前回のルックに続いて、今回は「動き」に注目しました。日本のアニメで言う1コマ打ち、2コマ打ちの考え方が、3DCGの作品の中で使われています。

## 考察

### 1. なめらかさは、表現の一つにすぎない

CGは、すべてのコマを計算してなめらかに動かせます。あえてコマを減らすと、動きに手描きのような「キレ」と「重さ」が出ます。なめらかさは選択肢の一つです。

### 2. 動きでキャラクターを描き分ける

同じ画面の中でも、キャラクターごとに動きの細かさが違うと、それぞれが別の世界から来たことが伝わります。動きそのものが、キャラクターの設定になっています。

### 3. はしごの「パラメータ」の例

1秒間に何枚描き変えるかは、まさにパラメータです。1年の今は、この違いに気づいて引き出しに集めておいてください。2年でAEを使うとき、そのまま使える引き出しになります。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 前回の振り返り：前回の分析シートを読み返す |
| 0:10〜0:50 | 主要場面を再上映（観点を絞って観る） |
| 0:50〜1:30 | 演習（個人） |
| 休憩 | — |
| 2コマ目 0:00〜0:30 | 演習の続き、ペアで見せ合う |
| 0:30〜0:50 | 数名が発表 |
| 0:50〜1:20 | 解説（この記事の考察） |
| 1:20〜1:30 | 引き出しノートに3つ、降ろす欄を記入 |

作品の本編は前回すべて上映しています。今回は場面を絞って再上映し、手を動かす時間を中心にします。

**この回の演習**

1場面の動きを観察し、なめらかな動きとカクカクした動きを書き分ける。それぞれの場面の感情を書く

降ろす面：この時期は「具体まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 動きがカクカクしていると感じた場面は、どんな感情でしたか。
2. なめらかな場面とカクカクした場面が切り替わる瞬間はありましたか。
