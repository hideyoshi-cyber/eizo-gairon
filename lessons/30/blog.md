# 1年分の作品を、1枚の地図にする　系譜マップの発表

**今日観た作品**

1年間で観た作品すべて（振り返り）

**宿題**

1年分の引き出しノートを見返し、一番多く集まった分類を書く

**次回**

企画書・コンセプトへの逆算（1）『千と千尋の神隠し』

**この記事の結論**　1年間で観た作品を、作り手、技術、源流の線でつなぐと、1枚の地図になります。地図を描けるようになったとき、作品は「点」ではなく「流れ」として見えるようになります。2年生からは、この地図を自分の制作のために使います。

（図：figures/lessons/30-image.svg）
図1　地図を描けるようになったとき、作品は「点」ではなく「流れ」として見える。

1年の最終回です。前期と後期で観た作品を、班ごとに1枚の系譜マップにまとめて発表しました。発表の前に、書籍の章トークとして「自分探しという勘違い」の章を紹介しました。

## この回で考えたこと

### 1. 地図の描き方

まず1年間の作品を時代順に並べます。次に、作り手が同じもの、技術が同じもの、源流が同じものを線でつなぎます。ゴジラの線、白黒の線、長回しの線、FFの線。線が多い作品ほど、ハブになっている作品です。

### 2. 1年で遡れたところ

2020年代から始めて、2010年代まで来ました。でも線をたどると、黒澤明、1954年の『ゴジラ』、1964年の『シェルブールの雨傘』まで源流が伸びています。2年生では2000年代、90年代を観ながら、この線をさらに太くしていきます。

### 3. 自分探しより、引き出し探し

「自分のやりたいことが分からない」という声を聞きます。でも、1年分の引き出しノートを見返せば、自分が何に反応してきたかは書いてあります。自分は探すものではなく、集めてきたものの中にあります。

（図：figures/lessons/30-diagram.svg）
図2　作品を時代順に並べ、線でつなぐと、線が多い作品がハブになる。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 進め方と講評の観点を伝える |
| 0:10〜1:30 | 班ごとの系譜マップ発表 |
| 休憩 | — |
| 2コマ目 0:00〜1:00 | 班ごとの系譜マップ発表の続き |
| 1:00〜1:15 | 全体講評 |
| 1:15〜1:30 | 次の目標を書く |

1人5分（発表3分＋質疑2分）で約30人分。人数が少ない場合は、他の人の作品や分析シートを分析シートで読み合う時間に充てます。

**この回の演習**

発表を聞きながら、他の人の発表から引き出しノートに使えるものを3つ集める

降ろす面：この時期は「具体まで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 自分の班の地図で、一番線が集まった作品は何でしたか。
2. 引き出しノートで一番多かった分類は何でしたか。それは自分のどんな好みを表していますか。
