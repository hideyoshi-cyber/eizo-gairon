# カメラを本物の戦闘機に載せた理由　『トップガン マーヴェリック』

**今日観た作品**

『トップガン マーヴェリック』（本編上映）

**宿題**

1986年の『トップガン』の予告編を観て、マーヴェリックとの違いを3つメモ

**次回**

ショット・カメラ・構図（後編）

**この記事の結論**　『トップガン マーヴェリック』は、6台のカメラを実際の戦闘機の操縦席に載せ、俳優が本物の重力を受ける顔を撮りました。ショットの説得力は、カメラを「どこに置くか」で決まります。そして1986年版のルックを意図的に引き継いだことで、36年の時間を一つの作品の中につなげています。

（図：figures/lessons/05-image.svg）
図1　操縦席に載せた6台のカメラと、カメラの置き場所のイメージです。

第5回と第6回は、ショット・カメラ・構図を扱います。前編の題材は『トップガン マーヴェリック』です。1986年の『トップガン』の続編で、空中戦の多くを実際の戦闘機で撮影したことで知られています。今回は「カメラをどこに置いたか」から作品を読みます。

## 続編までの36年

続編の企画は長く動いていました。2012年に脚本の草稿が書かれましたが、同年に前作の監督トニー・スコットが亡くなり、企画は止まります。2017年にコシンスキーが監督に決まって再始動し、完成した作品はスコットに捧げられています。

## 作り手のバックボーン

**ジョセフ・コシンスキー（監督）**　『トロン：レガシー』『オブリビオン』を手がけた監督です。コシンスキーがクルーズを続編に口説けた条件は、本物のジェット機で撮ることだったとされています。

**クラウディオ・ミランダ（撮影）**　コシンスキーと何度も組んできた撮影監督で、二人の共通の考えは「現実に勝るものはない」でした。前作の撮影監督ジェフリー・キンボールに話を聞き、グラデーションフィルターや薄い粒子で前作のルックを引き継いでいます。

**トム・クルーズ（主演・製作）**　俳優たちが実機の後席で撮影に耐えられるよう、数か月にわたる飛行訓練のプログラムを組みました。

## カメラをどこに置いたか

撮影チームは、海軍と1年以上かけて調整し、F/A-18の操縦席にカメラを載せる許可を得ました。ソニーと開発した小型カメラを使い、操縦席に6台、機体の外側に最大4台を取り付けています。前作では、空中にいるクルーズ本人を撮ることはできませんでした。

| 撮り方 | カメラの位置 | 画の役割 |
| --- | --- | --- |
| **機内** | 操縦席の中、俳優の顔の前 | 重力を受ける本物の表情 |
| **空対空** | 並走する撮影機 | 機体の動きと速度、地形との距離 |
| **地上から** | 地上のカメラ | スケール感、空母や基地の空気 |

## 考察：比較から何が言えるか

### 1. ショットの説得力は「カメラの位置」で決まる

操縦席の中のショットは、CGや合成でも作れます。それでも本物の機内にカメラを置いたのは、俳優の顔にかかる重力だけは再現できないからです。何を撮るかより先に、どこから撮るかを決めることが、ショットの質を決めています。

### 2. 6台同時撮影は、構図の判断を編集に持ち込む

機内では演出家がその場で指示できないため、6台のカメラで同時に撮り、どのアングルを使うかを編集で選んでいます。第4回の『1917』が「切らない」ために撮影段階で構図を決め切ったのに対し、本作は「選べる」ように撮っています。正反対の戦略です。

### 3. ルックで36年をつなぐ

前作のフィルターや粒子感を引き継いだことで、新しいデジタル撮影の画が、1986年の記憶と地続きに見えます。源流作品は、物語だけでなく「画の質感」でも引き継げるということです。

### 4. 実写主義はプリプロで決まっている

実機で撮るという判断は、主演を口説く条件であり、海軍との1年以上の調整や俳優の訓練を前提にしています。撮影現場の工夫ではなく、企画段階の決断です。

1. 機内のショットと、空対空のショットで、伝わるものはどう違いましたか。
2. 一番「本物だ」と感じたショットはどれですか。その理由は何ですか。
