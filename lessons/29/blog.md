# 遊ぶ時間と、観る時間をつなぐ演技　『The Last of Us』

**今日観た作品**

『The Last of Us』のムービーシーンと、冒頭のプレイ映像

**宿題**

好きなゲームの登場人物で、「演技がうまい」と思ったキャラクターを1人挙げる

**次回**

1年後期まとめ：系譜マップを作る

**この記事の結論**　『The Last of Us』は、俳優の身体と声を丸ごと記録する撮影方法で、ゲームの登場人物に映画と同じ演技を与えました。プレイヤーがカメラを持つ時間と、作り手がカメラを持つ時間が、同じ人物の演技でつながっています。

前期の第3回で、ゲームと映像の違いを「カメラの主導権」で整理しました。今回は、その境界を演技でつないだ作品です。2023年にはドラマ版も作られ、ゲームの物語が映像作品として受け継がれています。

## 作り手のバックボーン

**ノーティードッグ**　『アンチャーテッド』シリーズで、映画のようなゲームを作ってきたスタジオです。ムービーとプレイの境目をなくすことに取り組み続けています。

**ニール・ドラッカマン（脚本・ディレクター）**　ゲームの物語を、登場人物の関係で描くことにこだわった作り手です。開発チームは、同じ年に公開された映画『ゼロ・グラビティ』（第19回）にも、シンプルさと緊張感の点で通じるものを感じていたそうです。のちにドラマ版の制作にも関わっています。

**あわせて知りたい作り手**

### エイミー・ヘニッグ脚本・ディレクター

ノーティードッグで『アンチャーテッド』シリーズの脚本とディレクションを担った作り手です。『The Last of Us』の二人の監督も、彼女の完璧主義と人物へのこだわりを、物語づくりのお手本に挙げています。

## 考察

### 1. 演技が、主導権の切り替えを隠す

ムービーシーンの人物と、プレイ中の人物が同じ俳優の演技でできているので、主導権が切り替わっても人物がぶれません。第3回の『Ghost of Tsushima』はシステムで映画の瞬間を作りましたが、この作品は演技でつないでいます。

### 2. ゲームの物語が、ドラマになる

10年後にドラマ化されたのは、物語と人物がそれだけ強かったからです。ゲームも、長く続くIPの入口になります。

### 3. CGに演技を入れる

第16回の『シン・ゴジラ』で、CGの怪獣に人間の演技を入れた話をしました。ここでは、CGの人間に俳優の演技を入れています。CGを作る人は、演技を受け取る側でもあります。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：「カメラを持つのは誰か」という観点を伝える |
| 0:10〜0:25 | トレーラー・ムービーシーンを上映 |
| 0:25〜1:30 | プレイ映像を上映（「プレイ画面」の表の順に） |
| 休憩 | — |
| 2コマ目 0:00〜0:20 | 比較シート：ムービーとプレイで、時間とカメラの主導権がどう違うかを書く |
| 0:20〜0:50 | ペアで比較、数名が発表 |
| 0:50〜1:20 | 解説（この記事の考察） |
| 1:20〜1:30 | 引き出しノートに3つ、降ろす欄を記入 |

プレイ映像は実況や解説の声が入っていないものを選び、使う時間の位置を事前に控えておきます。

**この回の演習**

ムービーからプレイに切り替わる瞬間を3つ書き出し、それぞれで何が変わったか（カメラ・音・画質・文字）を書く

降ろす面：この時期は「具体まで」。パラメータの観察は引き出しノートに集めます。
