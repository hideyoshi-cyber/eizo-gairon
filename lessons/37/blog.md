# コンテは、時間の設計図　『時をかける少女』

**今日観た作品**

『時をかける少女』（本編上映）

**宿題**

一番印象に残ったカットを1つ選び、構図を簡単にスケッチしてくる

**次回**

絵コンテ（2）繰り返しの構図

**この記事の結論**　絵コンテは、絵の下書きではなく、時間の設計図です。どのカットを何秒見せ、どこで切り、どこで繰り返すか。『時をかける少女』は、同じ場所と同じ構図を何度も繰り返すことで、時間を飛び越える物語を観客に体験させています。

今回から3回は絵コンテです。2006年の細田守監督の『時をかける少女』を題材にしました。小さな規模で公開され、口コミで長く上映が続いた作品です。

## 考察

### 1. コンテは秒数を決めるもの

コンテには、絵と一緒に秒数が書かれています。同じ構図でも、3秒見せるか、10秒見せるかで意味が変わります。コンテは、時間を描く道具です。

### 2. 原作は1967年

この作品は、筒井康隆の1967年の小説を原作にしています。何度も映像化されてきた物語を、2006年の高校生の話として作り直しました。長く続く物語の、受け継ぎ方の例です。

### 3. 小さく始まった作品

公開の規模は大きくありませんでしたが、口コミで上映が長く続きました。大きな宣伝がなくても、作品の力で観客は増えていきます。

## 授業の進め方（90分×2コマ）

| 時間 | 内容 |
| --- | --- |
| 1コマ目 0:00〜0:10 | 導入：今回の観点を伝え、「観る前の予想」を書く |
| 0:10〜 | 本編上映（止めない・戻さない・飛ばさない） |
| 休憩 | 構成の区切りで休憩。前半で気づいたことを1行メモ |
| 2コマ目 | 上映の続き |
| 上映後 15分 | 分析シート「たどる面」を個人で記入 |
| 15分 | ペアで「授業で投げた問い」を話し合う |
| 15分 | 解説（この記事の考察） |
| 5分 | 引き出しノートに3つ、降ろす欄を記入 |

上映時間が長い場合は、ペアの話し合いを短くして解説の時間を確保します。

**この回の演習**

一番心が動いた場面を1つ選び、はしごを下からたどる。そのうえで、降ろす面を書く

降ろす面：この時期は「パラメータまで」。パラメータの観察は引き出しノートに集めます。

## 授業で投げた問い

1. 印象に残ったカットは、何秒くらい続いていましたか。
2. 同じ場所が何度も出てくることに、気づきましたか。
