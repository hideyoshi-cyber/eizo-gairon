# お金を集めるほど、予算が増えない　製作委員会方式のジレンマ

**この記事の結論**　製作委員会は、リスクを分け合うためにたくさんの会社でお金を出し合う仕組みです。でも岡田斗司夫さんは、出資する会社が主導権を守ろうとするほど、作品の予算は「中心の会社が出せる額」で頭打ちになり、本数だけが増えて現場は貧しいままだ、と指摘します。お金を集めるほど、主導権は失われる。このジレンマを知ることは、自分がどの立場で作品に関わるのかを考える出発点になります。

（図：figures/gaiden/05-image.svg）
図1　製作委員会は、リスクを分け合うためにたくさんの会社でお金を出し合う仕組みです。

[はじめに読む](#essay-01)の記事で、アニメや映画のお金の流れとして「製作委員会」を紹介しました。今回はその仕組みが抱える問題を、評論家の岡田斗司夫さんの解説をもとに考えます。岡田さんは、アニメ制作会社ガイナックスの創業メンバーの一人でもあり、業界の内側を知る立場から、この問題を繰り返し語っています。

## 製作委員会とは

製作委員会は、出版社、テレビ局、レコード会社、広告代理店、配信会社などが、お金を出し合って一本の作品を作る仕組みです。出した割合（出資比率）に応じて、作品の権利と、ヒットしたときの収益を分け合います。1本の失敗で会社が傾かないように、リスクを分け合うために広がりました。

ここで大事なのは、実際に絵を描いて作品を作るアニメ制作会社は、多くの場合この委員会に出資しておらず、決まった制作費で仕事を請け負う立場にいることです。

## 岡田斗司夫さんの指摘

岡田さんは、2016年12月の「岡田斗司夫ゼミ」で、製作委員会方式が日本のアニメーターを貧しくしている理由を、こう説明しています（要約）。

|  | 岡田さんの説明（要約） |
| --- | --- |
| **1. 出資者は口を出したい** | お金を出す会社は、作品への発言権を持ちたい。だから、委員会の中心になる会社（幹事会社）は、たとえば4割ほどの出資比率を自分で確保し、残りを多くの会社に小さく分けることで、主導権を握ろうとする |
| **2. 幹事が出せる額が、予算の上限になる** | 幹事会社が主導権を保てる比率を守ろうとすると、作品全体の予算は「幹事が出せる金額」から逆算して決まってしまう。本来なら20億円の作品に100社が出資してもいいはずなのに、そうはならない |
| **3. 予算が増えないまま、本数だけが増える** | 外からもっとお金を出したい会社が現れても、受け入れると主導権を失う。その結果、1本あたりの制作費は上がらず、作品の数だけが増え、現場に回るお金は増えない |

岡田斗司夫ゼミ（2016年12月25日配信）の内容を、本人のブロマガとnoteの記録をもとに要約しています。これは岡田さんの見方であり、業界の全員が同じ意見というわけではありません。

## ジレンマの正体

ここにあるのは、こういうジレンマです。

> リスクを分け合うために、たくさんの会社でお金を出し合う。でも、主導権を守るためには、予算を大きくできない。

予算を増やせば作品は良くなるかもしれない。けれど、そのためにお金を受け入れると、自分たちが作品を動かせなくなる。主導権を守れば、予算は増えない。そして、そのしわ寄せは、委員会の外にいる制作会社と、そこで働く人たちに来ます。

## 違う見方と、変わりつつある現場

一方で、製作委員会には良い面もあります。一般には、1本の作品が失敗したときの損失を一社で抱えずに済むよう、リスクを分け合うために広がった仕組みだと説明されます。出版社、音楽、グッズ、配信と、各社がそれぞれの窓口で作品を広げられるのも委員会の強みです。

そして、仕組みそのものも変わりつつあります。配信会社が一社で制作費を出すオリジナル作品が増え、第11回の『ルックバック』ではAmazon MGMスタジオが日本アニメの製作委員会に初めて加わりました。制作会社が自ら出資して権利を持つ動きも出てきています。どのやり方が正しいかではなく、自分が関わる作品が、どの仕組みで作られているかを知ることが大事です。

## 考察

### 1. 「誰が決めるのか」が、お金の量を決める

岡田さんの説明で一番大事なのは、予算の上限が作品の必要から決まるのではなく、「誰が主導権を持つか」から決まっている、という点です。お金の流れは、権力の流れでもあります。

### 2. 委員会の外にいることの意味

制作会社が委員会に入っていないと、作品がどれだけヒットしても、最初の制作費以上のお金は入りにくい。[はじめに読む](#essay-01)で話した「権利を持つ側と、作業を請け負う側」の話の、一番はっきりした例です。

### 3. 作り手として、仕組みを選ぶ側に回る

仕組みに文句を言うだけでは、何も変わりません。仕組みを知り、どの立場で関わるか、権利を持つ側に近づくにはどうするかを考える。それが、振り回される側から、操る側に回るということです。
