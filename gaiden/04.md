# 15秒の国と、30秒の国　広告の役目と、日本と海外の違い

**この記事の結論**　広告は、依頼主の課題を解くための映像です。日本は15秒が中心で、タレントの顔で一瞬にして信頼を作る方法が発達しました。海外は30秒以上が中心で、アイデアや物語で引きつける方法が発達しました。その違いの裏には、CMの枠の歴史と、広告代理店の立ち位置の違いがあります。どちらにも学ぶところがあり、Webの時代にはその境界も溶けつつあります。

第20回でCMの回を設けました。今回はその続きとして、広告の役目と、日本と海外の広告の違いを整理します。皆さんの多くが最初に関わるのは広告の仕事なので、自分が入っていく現場の「当たり前」が、世界ではどう違うのかを知っておいてください。

## 広告の役目

広告の役目は、大きく言えば3つです。知ってもらう（認知）、好きになってもらう（好意）、動いてもらう（行動）。CMはこの3つのどれを担うかによって、作り方が変わります。そして、お金を出しているのは依頼主です。広告は、作り手が作りたいものではなく、依頼主の課題を解くための映像です。

## 日本と海外の違い

|  | 日本 | アメリカなど海外 |
| --- | --- | --- |
| **CMの長さ** | 15秒が中心。1961年に15秒の枠が生まれ、標準になった。ある調査では日本のCMの約66％が15秒 | 30秒が中心で、60秒以上の長いものも多い。同じ調査ではアメリカの15秒CMは約32％ |
| **作り方** | 有名なタレントを起用して、一瞬で世界観と信頼を作る | アイデア、映像の面白さ、ストーリー、社会的なメッセージで引きつける |
| **タレントの起用** | 非常に多い。CMの出演本数がニュースになる | 少ない。調査によって数字は違うが、日本よりかなり少ないとされる |
| **広告代理店** | 大手の代理店は、媒体（テレビ局など）の側に立って広告枠を売る立場から育った。そのため、同じ業種の競合する会社を同時に扱うことがある | 依頼主の代理人として広告枠を買う立場から育った。そのため「一業種一社」が原則 |
| **映像作品との関係** | CMディレクターが映画監督になる例も多い（中島哲也『下妻物語』『告白』など） | CMやMVの監督が映画へ（リドリー・スコット、トニー・スコット、デヴィッド・フィンチャー、ミシェル・ゴンドリー） |

CMの長さの比率は、J-STAGEに掲載された日本とタイのテレビ広告の比較研究で引用されている調査によります。代理店の成り立ちの違いは、ムサシノ広告社のコラムをもとにまとめています。国や時期によって状況は変わるため、傾向として理解してください。

## 考察

### 1. 15秒の国の作り方

15秒が中心だから、日本のCMはタレントの顔で一瞬にして信頼と世界観を作る方法が発達しました。短い時間で伝えるための、合理的な選択です。ただし、タレントに頼ると、映像そのもののアイデアが育ちにくいという面もあります。

### 2. 代理店の立ち位置が、仕事の流れを決める

日本の大手代理店は、媒体の側から育ったという歴史があります。この違いは、皆さんが制作会社として仕事を受けるときの、お金の流れや意思決定の順番にも影響します。[はじめに読む](#essay-01)の表と合わせて読んでください。

### 3. 境界は、どんどん溶けている

テレビの枠に縛られないWebの映像では、日本でも長いブランド映像や、MVとCMの間のような作品が増えています。第2回のティロリミックスは、その代表です。15秒の技術と、長い尺で物語を語る技術。これからの作り手には、その両方が求められます。

### 4. 広告は、映画への遠回りではない

海外でも日本でも、広告の現場から映画監督が生まれています。短い時間で人を動かす技術は、どんな映像にも通じます。広告の仕事は、映像の最前線の一つです。
