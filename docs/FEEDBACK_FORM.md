# 感想提出フォーム

成績は「出席」と「毎回の感想の提出」。感想は内容の正誤では評価しない（CLAUDE.md）。

## 作り方
1. https://script.google.com で新しいプロジェクトを作り、`scripts/create-feedback-form.gs` の内容を貼る
2. `createFeedbackForm` を実行（初回は権限の承認が出る）
3. 実行ログに出る「回答用URL」を控える（編集用URLは先生だけが使う）
4. GitHubのリポジトリ変数 `FEEDBACK_FORM_URL` に回答用URLを設定して、デプロイを再実行する
   - 設定するまで、各回の「感想の提出」ボタンは表示されない

## 設問
| 設問 | 形式 | 必須 |
| --- | --- | --- |
| 回 | プルダウン（第1〜60回） | はい |
| 氏名 | 短い記述 | はい |
| 感想 | 長い記述 | はい |
| 匿名で掲載してよいか | 選択（載せてよい／載せない） | はい |
| メールアドレス | 自動で記録（Googleログイン） | 自動 |

## 運用
- 「みんなの気づき」に載せるのは、「載せてよい」を選んだ感想だけ。講師が選び、匿名にして記事に追記する
- 未決：学校の学生が学校ドメインのGoogleアカウントを持っているか（持っていれば、フォームを学校ドメイン内に限定できる）
