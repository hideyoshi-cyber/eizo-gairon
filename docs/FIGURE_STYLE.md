# 図の書式（各回のイラストと図式）

各記事に2枚入れる。ファイルは `figures/lessons/NN-image.svg`、`figures/lessons/NN-diagram.svg`（外伝は `figures/gaiden/NN-image.svg`、`NN-diagram.svg`）。NNは2桁。

## 共通
- SVGは自己完結：外部画像・外部フォント・script・foreignObject・xlink:href を使わない。`<?xml?>` 宣言なし
- 先頭に `role="img" aria-labelledby="IDt IDd"` と `<title>`、`<desc>`。IDは**ファイルごとに一意**（例：`l07i-t`、`l07i-d`、`l07d-t`、`l07d-d`）。1ページに2枚入るため
- 色はCSS変数だけを使う（ライト／ダーク両対応）：`var(--ink)` 文字、`var(--sub)` 補足、`var(--panel)` 面、`var(--rule)` 線、`var(--paper)` 地、時代色 `var(--c20)` `var(--c10)` `var(--c00)` `var(--c90)`。固定色は var() のフォールバックとして `var(--ink,#1A1D24)` の形で書く
- 回→主色：第1〜15回=c20、第16〜30回=c10、第31〜45回=c00、第46〜60回=c90、外伝=c00
- 文字は `font:700 19px "Zen Kaku Gothic New","Hiragino Sans",sans-serif`（段名）、`500 14.5px`（本文）、`500 12.5px`（補足）。最小12px
- 日本語1行は全角28字以内（幅520pxの枠）。長いときは行を分ける
- スタイルは `<style>` に `.fig-xxx .cls{…}` の形で書く。クラスは必ず `fig-lNNi` / `fig-lNNd` で始める（ページ内で衝突させない）
- 手本：`figures/abstraction-ladder.svg`、`figures/backbone-rebuild.svg`

## イラスト（NN-image.svg）
- viewBox `0 0 560 315`（16:9）。その回のテーマを**抽象的な図案**で表す：色の面、線、円、グリッド、リズム、構図の分割など
- 実在の作品の再現、キャラクター、ロゴ、人物の絵、スチルに似せた絵は**描かない**（CLAUDE.md：映画のスチルや画像は載せない）
- 文字は入れても短い見出し1つまで。説明は図のキャプションに書く
- 90年代の画面（グリッド、走査線、グラデーションの床）の空気を少し入れてよい

## 図式（NN-diagram.svg）
- viewBox は幅560、高さは内容に合わせる（最大700）。箱、矢印、段、軸、表など、記事の考察を図にする
- **内容は、その記事に書いてあることだけ**。新しい事実、数字、固有名詞、作品名を足さない。記事の言い回しを短くして使う
- 見出しは記事の考察の要点（2〜5項目）。順序や因果は記事のとおりにする

## 記事への入れ方（Markdown）
空行で区切った段落で、次の2行1組。
```
（図：figures/lessons/NN-image.svg）
図1　キャプション（1文。記事にある言葉で）
```
- イラスト：「**この記事の結論**」の段落の直後
- 図式：「## 授業の進め方（90分×2コマ）」の見出しの直前
- 図の番号は記事の中で、イラストが「図1」、図式が「図2」
- 記事のそれ以外の文章は、一切変更しない
