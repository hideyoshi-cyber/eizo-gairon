# Claude Code に最初に渡す指示（コピーして使う）

このリポジトリは、僕が担当する授業「映像概論」の教材サイトです。まず CLAUDE.md と docs/HANDOFF.md を読んでください。

最初にやってほしいこと：
1. リポジトリ全体の構成を確認し、`curriculum/plan.yaml` と各Markdownの対応が取れているかチェックして、不整合があれば一覧にしてください（直す前に報告）
2. `site-prototype.html` の見た目と構成を参考に、Markdownから静的サイトを生成する仕組みを提案してください（Astroを第一候補。GitHub Pagesで公開し、独自ドメインを後で設定できる形）
3. 提案に合意したら、トップ、授業記録、各回、外伝、60回の地図、分析シート、年表、スタジオ、用語集、書棚、リンク集、この授業について、のページを生成できるところまで作ってください

守ってほしいこと：
- 文章のルール、著作権、ファクトチェックの手順は CLAUDE.md に従う
- 記事の中身（事実や主張）は、僕の確認なしに書き換えない。書式の調整はOK
- Amazonのタグは、僕が「サイトを登録した」と言うまで付けない
